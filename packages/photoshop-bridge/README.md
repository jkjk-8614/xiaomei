# 无限画布 PS 桥接插件

这是一个 Photoshop UXP 面板插件，用于把无限画布里的本地图片回传到 Photoshop，并尽量作为智能对象导入。

## 使用前提

- Photoshop 24.0 或更高版本。
- 已安装 Adobe UXP Developer Tool。
- 无限画布后端正在运行，默认地址为 `http://127.0.0.1:3000`。
- 无限画布项目版本需要包含 `/api/photoshop-bridge/...` 桥接接口。

## 安装方式

1. 解压安装包。
2. 打开 Adobe UXP Developer Tool。
3. 点击 `Add Plugin`。
4. 选择解压后的 `photoshop-bridge` 文件夹里的 `manifest.json`。
5. 点击 `Load`。
6. 在 Photoshop 菜单中打开 `Plugins > 无限画布`。

## 使用方式

1. 先启动无限画布服务。
2. 在 Photoshop 中打开插件面板。
3. 在无限画布中选择图片，点击 PS 回传按钮。
4. 插件会自动拉取队列并导入到 Photoshop。

如果画布提示“已进入 Photoshop 队列”但图片没有出现，请确认插件面板保持打开且连接状态为在线；未加载插件时，图片只会暂存在无限画布服务的本地队列中。

## 功能

- PS 在线状态心跳。
- 自动导入回传图片。
- 手动导入最新图片。
- 最近任务列表。
- 队列清理。
- 缩略图预览。
- 优先作为智能对象导入，失败时使用备用导入方式。
- AI 分层面板的“在 Photoshop 打开”会将 PSD 打开为独立文档，保留全部图层；普通图片回传继续置入当前文档。需要在 UXP Developer Tool 重新加载此目录的插件代码。插件心跳包含 `open-layered-psd` 能力后，画布才会启用发送链路；画布提示进入队列不等于 Photoshop 已完成打开。

当前面板版本：V1.0.2。

## 注意

- 当前网络权限为 `domains: "all"`，这是为了兼容 Photoshop v27.7 对本地 `127.0.0.1:3000` 权限匹配的限制。
- 插件本身不包含无限画布后端，不能脱离无限画布服务单独工作。
- 如果对方电脑上的无限画布端口不是 `3000`，需要在插件面板里的“服务地址”里修改。
