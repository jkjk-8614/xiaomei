# 批量视频工作台（分享版）

## 启动

1. 在 Windows 电脑上解压整个压缩包。
2. 安装 Node.js 18 或更高版本，然后双击 `start.bat`。
3. 工作台会自动打开浏览器。首次使用时打开“连接与运行设置”，填写所需接口密钥。

## 素材服务器设置

分享版不预设素材服务器信息，自动上传默认关闭。需要生成前自动上传素材时，在设置中填写 SFTP 主机、SSH 端口、用户名、远程素材目录、素材公网 HTTPS 地址前缀，并粘贴本机专用的 SSH 私钥，然后开启“生成前自动上传素材”。远程目录应与公网地址前缀对应；第三方视频接口需要能公开读取参考图片。

不要把 API 密钥、SSH 私钥或本机 `data` 目录放入再次分享的压缩包。每台电脑的设置和任务记录只保存在自己的 `data` 目录。

## 音色与输出

内置“营销宣传”12 个音色和“旁白朗诵”19 个音色。音色列表与试听 MP3 已包含在压缩包中；试听不需要 Fish Audio API Key，正式配音需要有效密钥。配音合成保留原视频流，只编码音频。

生成的视频保存在程序目录下的 `输出` 文件夹，图片素材放在 `素材` 文件夹，每个子文件夹为一个素材组。
