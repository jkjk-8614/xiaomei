# 小美画布网页素材采集

## 安装或更新

在 Chrome 打开 `chrome://extensions/`，开启开发者模式，选择「加载已解压的扩展程序」，再选择 `tools/chrome-local-asset-importer`。已从同一路径加载的扩展可点击「重新加载」，继续使用原有服务地址、文件夹和分类选项。

## 采集

1. 打开要采集的网页，从工具栏打开「小美画布网页素材采集」。需要连续采集时可打开侧边栏。
2. 点击「扫描当前页面图片」。可开启低分辨率过滤或自动翻页加载，也可点击「截图」采集当前可见画面。
3. 勾选素材后，可直接下载。单项保存原文件，多项以填写的文件夹名打包 ZIP。
4. 导入时先启动小美画布，填写本机地址并点击「连接」。默认地址是 `127.0.0.1:3000`。选择分类平台和模型后，点击「导入资产库」。保存结果在素材库的「本地素材」中查看。

扫描可读取网页及可访问 iframe 中的图片、普通视频、SVG 内的图片引用、可读取的画布和 Blob，也会收集当前标签页加载的直链视频。流媒体清单提供链接复制。跨域受限的画布可尝试截图，截图范围为可见视口。

扩展使用网页访问权限读取素材和截取活动标签页。导入时由浏览器读取所选文件，再把文件内容交给本机小美画布。连接入口返回可选的分类平台和模型。
