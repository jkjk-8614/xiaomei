# 小美画布模型下载扩展

在 Chrome 或 Edge 打开扩展管理，开启开发者模式，选择“加载已解压的扩展”，选中本目录。也可以在小美画布“ComfyUI → 本地模型 → 浏览器发送”下载 ZIP，解压后加载。

保持小美画布运行，打开 Civitai 或 Hugging Face 模型页面，点击扩展图标，再点击“发送并选择文件”。小美画布会打开版本与文件选择页；选好保存目录后点击“下载所选文件”。

接收地址必须为本机 HTTP 地址。应用端口变化时，从“浏览器发送”复制新地址并填入扩展。

扩展只读取点击时的当前标签页地址，并保存本机接收地址；不读取页面内容、Cookie 或账号密钥。
