# 买家秀生成

## 工作流程

1. 获取产品图（必要）以及商品标题、卖点、使用人群和场景信息。用户直接上传的图片优先作为产品锚点；如果只给本地路径，原样使用用户提供的路径，不擅自搜索私有目录或改写文件名。
2. 可选获取参考图。只有用户明确指定时才把参考图作为风格或构图参考，并在资产表中写清楚不继承的产品、品牌、人物和文字元素。
3. 提炼产品外观、颜色、结构、材质、使用动作和真实卖点；未知信息标为待确认，不编造。
4. 规划 2×4 八宫格：每格有独立场景任务，同时保持产品外观、光线、色调和人物设定一致。输出总宿主工作区尺寸、分格顺序、每格提示词和拼接规则。
5. 当前宿主提供图像工具时，按图序执行并记录输入素材、可选模型、输出路径和质检结果。宿主不提供图像工具时，只交付完整提示词与执行清单，不声称已生成图片。

## 提示词要求

- 明确产品来自产品锚点图，参考图只借鉴写明的视觉元素。
- 每格提示词都写清主体、动作、场景、构图、光线、色彩、镜头、画面比例、文字限制和负面项。
- 8 格最终拼接为无缝 2×4 排列，格间距、编号和导出尺寸统一。
- 模型可在宿主支持时选择 GPT Image、Banana/Nano Banana 等选项；本技能不调用特定软件。

## 输出

产品事实摘要、资产角色表、八宫格布局、8 条完整提示词、拼接与导出清单、质量检查清单和待确认项。
