# 主图洗图

## 概述

基于竞品的标题、SKU和主图，识别目标商品，概括出[商品主图描述]，结合[视觉升级规范]带入提示词模板得到完整提示词。
基于竞品的主图和提示词，使用当前宿主生图能力，以 `当前宿主工具` 图生图的方式生成**点击率更高、视觉更精致**的同款主图。`当前宿主工具` 的安装、授权、宿主工作区、保存路径、结果展示和错误处理规则，以基础技能 `当前宿主工具` 的当前说明为准；如果本技能中的业务步骤与 `当前宿主工具` 基础技能的工具规则冲突，优先遵守 `当前宿主工具` 基础技能。

> 「视觉升级规范」提炼步骤，从竞品 5 张主图分析中提取视觉规律，明确升级方向（背景/光线/色调/产品占比/整体气质），让新图在视觉精致度上系统性地超越竞品。

## 前置条件

- 至少确认一张产品锚点图或用户明确接受无图风险。
- 明确产品图、竞品图、参考图和包装图的角色；不把竞品事实带入本商品。
- 由当前宿主决定是否提供图像工具、支持哪些模型和保存位置。

## 工作流程

1. 获取并分类目标商品主图、参考图和可选评价数据，记录资产角色。
2. 解析目标图的产品事实、卖点、用户顾虑、构图、色彩、光线和信息层级。
3. 提炼视觉升级规范，按图序分配点击、卖点、场景、信任和收口任务。
4. 为每张图输出完整中文提示词，明确产品锚点、参考边界、负面项和文字安全区。
5. 当前宿主提供图像工具时按图序执行；不提供时输出提示词、素材映射、参数建议和质检清单。
6. 检查产品一致性、事实准确性、文字可读性和套图连续性。

## 任务分支：单张局部换框/换材质

当用户明确要求“图1为主体、图2只参考相框边/材质、照片和文案不变、只替换相框边”等局部编辑时，优先执行单张局部改图，不要强行规划五张主图或补足套图：

1. 把图1标为唯一主体图；图2及后续图片只标为边框样式/材质参考，不得把参考图中的照片、文字、背景或品牌事实带入主体。
2. 先锁定不可改变项：照片内容、人物、文案、背景、构图、比例、位置、透视、内框开口和画面内容。
3. 只修改目标边框的颜色、材质、线条层次和装饰；要求四边宽度统一、四角与接缝连续、正面和侧面厚度真实，不要照搬参考图的尺寸或透视。
4. 只生成一张完整图片，禁止拼图、宫格、多图排版或擅自扩展成套图；没有蒙版工具时，不声称已经做到像素级锁定。
5. 生成提示词必须同时写清主体图、参考图角色、保留项、修改项和负面项，确保生图模型知道“只改哪里”。

## 注意事项

- 本技能只输出分析、策划、提示词、资产映射和验收清单，不绑定特定命令、服务或保存目录。
- 当前宿主提供图像工具时按图序执行；不提供时不声称图片已经生成。
- 竞品图只提供可迁移的视觉参考，不能替代产品锚点，也不能带入竞品品牌、文案或产品事实。
