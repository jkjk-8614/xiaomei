# 主图套款

## 概述

用户上传**自己的产品图**作为主体,同时获取**竞品5张主图**作为视觉方案参考。分析竞品的视觉规律后,提炼出[视觉升级规范],然后将**用户自己的产品**套用到竞品的构图/背景/光线/氛围中,生成同款风格的主图。

使用当前宿主生图能力,以 `当前宿主工具` 的**多图生图**方式执行。`当前宿主工具` 的安装、授权、宿主工作区、保存路径、结果展示和错误处理规则,以基础技能 `当前宿主工具` 的当前说明为准;如果本技能中的业务步骤与 `当前宿主工具` 基础技能的工具规则冲突,优先遵守 `当前宿主工具` 基础技能。
- **第1张参考图** = 要复刻的竞品主图(告诉AI「用这个构图/背景/氛围」)
- **第2张及之后的参考图** = 用户上传的产品图(告诉AI「主体产品长这样」)

> **与「主图洗图」的核心区别**:洗图是复刻竞品产品本身;套款是**保留竞品的视觉方案,但替换为用户自己的产品**。

## 前置条件

- 至少确认一张产品锚点图或用户明确接受无图风险。
- 明确产品图、竞品图、参考图和包装图的角色；不把竞品事实带入本商品。
- 由当前宿主决定是否提供图像工具、支持哪些模型和保存位置。

## 工作流程

1. 获取并分类产品图与竞品主图，记录每张图的角色。
2. 解析竞品套图的图序、构图、背景、光线、信息层级和可迁移规则。
3. 提炼产品锚点的外观、材质、颜色、结构和不可改变事实。
4. 为每张图输出换品后的完整中文提示词，明确可借鉴与必须排除的元素。
5. 当前宿主提供图像工具时按图序执行；不提供时输出提示词、素材映射、参数建议和质检清单。
6. 检查产品一致性、文字安全区、套图连续性和竞品元素排除情况。

## 注意事项

- 本技能只输出分析、策划、提示词、资产映射和验收清单，不绑定特定命令、服务或保存目录。
- 当前宿主提供图像工具时按图序执行；不提供时不声称图片已经生成。
- 竞品图只提供可迁移的视觉参考，不能替代产品锚点，也不能带入竞品品牌、文案或产品事实。
