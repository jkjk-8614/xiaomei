# A2-市场洞察·五类词根需求拆解

## 一、技能概述

将搜索关键词按 **功能 / 材质 / 人群 / 场景 / 款式** 5 类词根拆解，量化每类词根的需求强度、竞争难度与蓝海机会，输出标准化 Excel 报告（7 Sheet）。

| 项目 | 内容 |
|:---|:---|
| **技能编号** | A2 |
| **核心数据源** | 生意参谋「搜索关键词」导出表（.xlsx） |
| **输出格式** | Excel（7 个 Sheet） |

## 二、执行流程（AI 必须按此顺序执行）

### Step 1: 接收用户输入

确认以下信息：
1. **品类名称**（如"亚麻裤男"、"行李箱侧开盖"）
2. **核心品类词**（用于从搜索词中去除干扰，如"亚麻裤"、"行李箱"）
3. **数据源文件路径**（生意参谋搜索词 Excel 文件）
4. **输出目录**（默认用户工作目录的 `表格/`）

### Step 2: 读取数据源，确认列名

读取用户提供的 Excel 文件，确认必须包含以下列：
- `相关搜索词`
- `预估搜索人气`
- `预估点击人数`
- `预估支付买家数`
- `点击率`
- `预估支付转化率`（或 `CVR`）
- `需求供给比`
- `天猫商品点击占比`

> 若列名不同（如生意参谋导出表头有差异），在读取时做列名映射，不要要求用户手动修改。

### Step 3: 构建五类词根词典

从搜索词中高频出现的 **功能 / 材质 / 人群 / 场景 / 款式** 词汇中提取词根，构建词根词典。

**提取原则：**
- 优先从搜索词中直接提取（数据驱动），而非凭经验编造
- 每类词根内部 **按字符串长度降序排列**（长词根优先匹配）
- 词根数量控制在 10-40 个/类，避免过度拆分

**示例（亚麻裤男）：**
```json
{
  "功能": ["加肥加大", "拉链口袋", "抗皱", "宽松", "修身", "直筒", "束脚", "薄款"],
  "材质": ["莱赛尔天丝", "桑蚕丝", "天丝", "莱赛尔", "冰丝", "纯亚麻"],
  "人群": ["中老年", "青少年", "高个子", "小个子", "儿童"],
  "场景": ["夏季", "夏", "休闲", "外贸"],
  "款式": ["老钱风", "中国风", "日系", "白色", "黑色", "高端品牌", "优衣库"]
}
```

### Step 4: 构建标题规则（可选）

如果用户没有特别要求，使用默认规则。否则根据品类特点配置 `title_rules`：

```json
{
  "default_suffix": "夏季薄款宽松直筒休闲裤",
  "root_overrides": {
    "薄款": "夏季宽松直筒休闲裤",
    "宽松": "夏季薄款直筒休闲裤"
  },
  "category_overrides": {
    "场景": {"夏": "薄款宽松直筒休闲裤"}
  }
}
```

### Step 5: 生成 JSON 配置文件

将以上信息写入 `a2_config.json`：

```json
{
  "input_path": "表格/数据源.xlsx",
  "output_path": "表格/[品类]_A2_五类词根需求拆解.xlsx",
  "category_name": "品类名称",
  "core_product_word": "核心品类词",
  "root_dict": {
    "功能": [...],
    "材质": [...],
    "人群": [...],
    "场景": [...],
    "款式": [...]
  },
  "title_rules": {
    "default_suffix": "...",
    "root_overrides": {},
    "category_overrides": {}
  }
}
```

### Step 6: 执行脚本

调用技能目录下的脚本生成报告：
```bash
python /技能目录/scripts/build_A2.py --config a2_config.json
```

### Step 7: 输出结果

在最终回复中输出完整的文件路径，使用 Markdown 超链接样式：
```
报告已生成：[品类_A2_五类词根需求拆解.xlsx](file://完整路径)
```

## 三、7 Sheet 结构

| Sheet | 名称 | 内容 |
|:---|:---|:---|
| 1 | 词根需求总览 | 品类概览指标 → 5类词根体系概览 → 全词根排名 → 品类总洞察 |
| 2 | 分类目词根拆解 | 每类词根独立展示（词根/出现词数/平均搜索人气/CVR/供给比/综合指数） |
| 3 | 词根需求强度矩阵 | 5维评分（需求规模/转化效率/竞争压力/蓝海机会/商业价值）+ 策略建议 |
| 4 | 词根交叉组合路径 | TOP20 词根两两交叉，发现组合需求路径 |
| 5 | 蓝海词根挖掘 | 蓝海词根（供给比高+CVR>3%）→ 轻竞争词根 → 3级蓝海策略 |
| 6 | 词根盈利诊断 | 盈利 TOP10 + 需优化 TOP10 |
| 7 | 词根行动策略 | 三级行动策略（P0紧急/P1重要/P2观察）+ 标题建议 |

## 四、评分算法

所有评分统一为 0-10 分：

| 维度 | 计算方式 | 说明 |
|:---|:---|:---|
| **需求规模** | `平均搜索人气 / 最大值 * 10` | 用**平均**搜索人气 |
| **转化效率** | `平均CVR / 最大值 * 10` | 百分比形式参与计算 |
| **竞争压力** | `平均供给比 / 最大值 * 10` | 越高表示竞争越激烈 |
| **蓝海机会** | `供给比≤0 → 10分；否则 1/(1+供给比)*100` | 供给比为0时直接给满分 |
| **商业价值** | `平均买家数 / 最大值 * 10` | 用**平均**买家数 |
| **综合指数** | `需求规模*0.3 + 转化效率*0.25 + (10-竞争压力)*0.15 + 蓝海机会*0.2 + 商业价值*0.1` | 保留2位小数 |

## 五、词根提取规则

1. **按长度降序排列**：每类词根内部按字符串长度从长到短排序，优先匹配长词根（如"莱赛尔天丝"优先于"天丝"）
2. **位置去重**：使用字符位置区间 `(start, end)` 判断是否重叠，已匹配的词根位置不可被其他词根覆盖
3. **去除核心品类词**：匹配前先将搜索词中的核心品类词替换为空，避免干扰词根提取

## 六、标题建议规则

1. **避免词根与品类名称重复**：如品类为"亚麻裤男"，词根"男"已在名称中，不可重复叠加
2. **材质类词根前置**：如"天丝亚麻裤男"（材质在前，品类在后）
3. **功能词根避免与后缀重复**：如词根为"薄款"，后缀不可再写"薄款"
4. **场景词根去季节重复**：如词根为"夏/夏季"，后缀中的"夏季"应省略

## 七、样式规范

- 字体：微软雅黑
- 表头：深绿色底(375623) + 白字
- 标题行：深棕底(2D2006) + 金字(FFD700)
- 数据行交替：白色(FFFFFF) / 浅灰(F5F5F0)
- 词根类别emoji：🔴功能 🟠材质 🟡人群 🟢场景 🔵款式

## 八、关联技能

- **上游输入**: A1-品类赛道扫描（确定分析品类和数据源）
- **下游输出**: A3-竞品主图分析、B1-上架策略制定

## 九、注意事项

1. 数据质量直接影响分析结果，务必确认数据源完整性
2. 品类差异可能导致词根词典需要调整，不要机械套用其他品类的词根
3. 词根提取基于字符匹配，同义词（如"夏"和"夏季"）需同时收录
4. 输出前务必检查 Sheet5 的蓝海词根排名是否连续（1,2,3...），禁止出现跳号
