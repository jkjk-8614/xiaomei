# C1-需求解码·评价需求深度分析

## 适用场景
- 用户提供了：
  - 评价数据表（多品牌/多链接评价汇总）
  - 问大家数据表（购买前真实疑问汇总）
  - 搜索词数据表（生意参谋/市场搜索关键词）
- 目标不是普通词频统计，而是输出一套可直接用于**爆款定位、SKU规划、差异化壁垒设计**的6-Sheet标准化经营分析表。

## 严格参考

1. **scripts/** 目录中存放了 Python 脚本模板（`build_C1.py`），执行时应：
   - 直接读取并参考该脚本的结构和样式定义
   - 使用 `openpyxl` 库创建 `Workbook`
   - 严格按照脚本中的样式对象（`fill_title`, `fill_section`, `fill_header`, `fill_alt`, `fill_white`，字体、对齐等）生成表格
   - 包含 `merge_title()`, `write_section()`, `write_header()`, `write_data_row()`, `set_col_widths()` 等辅助函数
   - 每个 Sheet 包含：大标题 → 分节标题 → 表头行 → 数据行 → 冻结首行

2. **绝对禁止使用 `pandas` 的 `to_excel()` 或类似简易导出方式**，这会导致格式完全不符合模板要求。

3. **正确做法**：
   - 读取原始数据（Excel 文件）
   - 分析并提取关键信息（评价词频、问大家问题分类、搜索词排序）
   - **参照 `scripts/build_C1.py` 的代码结构**，生成符合格式的 Excel
   - 使用 `openpyxl` 逐单元格写入数据和样式

4. **输出产物**：
   - 默认命名为：`[品类]_C1_评价需求深度分析.xlsx`
   - 默认保存到 宿主 工作区（`\宿主\表格`）
   - 必须告诉用户完整的文件名称和路径

## 这类技能的核心理解（非常重要）

这不是普通"需求结构分析表"，也不是纯搜索词统计表。
它的本质是：

> 把评价、问大家、搜索词三类数据交叉验证后，最终收束成"爆款需求定位 + SKU/价格策略 + 差异化壁垒路线"的经营决策表。

用户一旦说"按参考示例做"或"不要修改表格呈现逻辑"，默认必须理解为：
- 不自由发挥改结构
- 不擅自升级字段
- 不擅自改变模块顺序
- 优先严格复刻参考示例的原始呈现逻辑

## 固定输出结构（6 Sheet）

1. `数据全景概览`
2. `需求优先级分析`
3. `行业搜索词分析`
4. `竞品差异化画像`
5. `SKU尺寸与价格策略`
6. `差异化壁垒与蓝海策略`

## 固定呈现逻辑（分段式模块化表格）

每个 Sheet 的结构是：
- 第1行：整行合并大标题（A1 到末列），深棕底金字
- 第2行起：分节标题（如"一、数据源全景"），深蓝底白字，合并整行
- 每个分节下方是独立分析模块（表头+数据行）
- 整体是"模块化经营分析版式"，不是平铺流水表

## 各 Sheet 详细规范

### Sheet1：数据全景概览

**大标题**：`{品类名}-C1评价需求深度分析-数据全景概览`

**分节1：一、数据源全景 - 4维数据概览**
表头：数据维度 / 数据量 / 数据来源 / 核心发现 / 数据质量 / 覆盖度 / 关键指标 / 备注
- 评价数据行：数据量、来源品牌、痛点TOP3、数据质量、有效覆盖率、正面提及次数、备注
- 问大家数据行：数据量、来源品牌、核心发现、数据质量、覆盖问题数、平均每问题回答数、备注
- 搜索词数据行：数据量、来源平台、蓝海词数量、数据质量、覆盖度、搜索量TOP1、备注

**分节2：二、4品牌评价量对比**
表头：品牌 / 评价数 / 占比 / 核心卖点 / 核心痛点 / SKU特点 / 差异化方向 / 竞争定位
- 列出各品牌评价数、占比、核心卖点/痛点、SKU特点、差异化方向、竞争定位

**分节3：三、评价关键词频TOP20**
表头：排名 / 关键词 / 提及次数 / 提及率 / 需求类别 / 优先级 / 竞争评级 / 建议
- 从评价文本中提取TOP20关键词，按提及频次排序
- 需求类别：痛点 / 正面 / 决策
- 优先级：🔴P0 / 🟠P1 / 🟡P2 / 🟢P3
- 竞争评级：🔴红海 / 🟠高竞争 / 🟡中竞争 / 🟢轻竞争 / 🔵纯蓝海

### Sheet2：需求优先级分析

**大标题**：`{品类名}-C1需求优先级分析-12维矩阵+决策路径`

**分节1：一、12维需求优先级矩阵**
表头：需求维度 / 类别 / 说明 / 评价提及率 / 问大家提及率 / 搜索词覆盖 / 搜索量 / 综合优先级 / 核心需求词 / 标题词根建议

12维需求（按品类适配，以下为通用框架）：
1. 材质品质（痛点）
2. 外观颜值（正面）
3. 容量大小（痛点/正面）
4. 轮子顺滑（痛点）
5. 尺寸规格（决策）
6. 侧开方便（正面）
7. 重量轻便（痛点）
8. 拉链安全（痛点）
9. 拉杆质量（痛点）
10. 人群定位（定位）
11. 使用场景（定位）
12. （第12维根据品类补充，如：功能设计/做工细节/包装物流等）

每维需填写：评价提及率/次数、问大家提及率/占比、搜索词覆盖数、搜索量级、综合优先级、核心需求词、标题词根建议。

**分节2：二、购买决策路径(问大家验证)**
表头：决策阶段 / 核心问题 / 提及频次 / 买家焦虑 / 营销应对 / 主图表达 / 详情页 / 客服话术 / 评价引导 / 优先级
- 从问大家中提取购买前核心决策问题
- 按决策阶段排序（材质确认→尺寸选择→功能验证→售后保障…）
- 每阶段给出：买家焦虑、营销应对、主图表达、详情页、客服话术、评价引导

### Sheet3：行业搜索词分析

**大标题**：`{品类名}-C1行业搜索词分析-TOP20+蓝海词`

**分节1：一、搜索量TOP20核心词**
表头：排名 / 关键词 / 搜索人数 / 点击人数 / 点击率 / 支付人数 / CVR / 竞争评级 / 策略建议
- 按搜索量降序排列TOP20
- CVR格式：如"6.0%"
- 竞争评级：🔴红海 / 🟠高竞争 / 🟡中竞争 / 🟢轻竞争 / 🔵纯蓝海
- 策略建议：对应竞争评级的标准话术

**分节2：二、蓝海词TOP20(供给比≥10)**
表头：排名 / 蓝海词 / 搜索人数 / CVR / 支付人数 / 竞争评级 / 蓝海机会 / 建议分组 / 标题占位建议
- 筛选供给比≥10或竞争度低的词
- 给出蓝海机会描述和标题占位建议

### Sheet4：竞品差异化画像

**大标题**：`{品类名}-C1竞品差异化画像-品牌矩阵+关键词对比`

**分节1：一、品牌竞争矩阵**
表头：维度 / 竞品A / 竞品B / 竞品C / 竞品D / 市场空白 / 我方突破 / 壁垒难度 / 优先级 / 建议动作
- 维度包括：材质品质、外观颜值、容量设计、轮子体验、核心功能、重量轻便、稳固性、价格定位、人群覆盖等
- 每个竞品给出当前定位
- 市场空白：该维度未被满足的需求
- 我方突破：建议的差异化方向
- 壁垒难度：高/中/低
- 优先级：🔴P0 / 🟠P1 / 🟡P2 / 🟢P3

**分节2：二、竞品评价关键词对比**
表头：关键词 / 竞品A / 竞品B / 竞品C / 竞品D / 合计 / 提及率 / 需求类别 / 差异化机会 / 优先级
- 提取评价中高频关键词，分品牌统计提及次数
- 计算合计和提及率
- 识别差异化机会（如"某品牌在该词上明显领先/落后"）

### Sheet5：SKU尺寸与价格策略

**大标题**：`{品类名}-C1SKU尺寸与价格策略-3维分析`

**分节1：一、尺寸搜索量与竞争分析**
表头：尺寸 / 搜索量 / 评价占比 / CVR / 竞争 / 场景 / 人群 / 定价 / 优先级 / 备注
- 按尺寸/规格维度统计搜索量、评价占比、转化率、竞争度
- 给出场景、人群、定价建议

**分节2：二、材质类型对比**
表头：材质 / 搜索量 / CVR / 价格带 / 卖点 / 痛点 / 人群 / 竞争 / 差异化 / 优先级
- 对比各材质类型的搜索表现、转化、价格带、卖点痛点
- 给出差异化方向和优先级

**分节3：三、价格带竞争分析**
表头：价格带 / 定位 / 竞品 / 利润率 / 人群 / 策略 / SKU数 / CVR / 风险 / 优先级
- 划分价格带（如低价入门/中端品质/高端旗舰）
- 每个价格带给出：定位、主要竞品、利润率、人群、策略、SKU数、CVR、风险

### Sheet6：差异化壁垒与蓝海策略

**大标题**：`{品类名}-C1差异化壁垒与蓝海策略-20壁垒+蓝海矩阵`

**分节1：一、20种差异化壁垒方向**
表头：编号 / 方向 / 核心表达 / 主图逻辑 / 详情页 / 搜索词 / SKU / 定价 / CVR
- 列出20个可落地的差异化壁垒方向
- 每个方向包含：核心表达话术、主图视觉逻辑、详情页布局、覆盖搜索词、对应SKU、定价区间、预期CVR

**分节2：二、蓝海策略矩阵**
表头：编号 / 方向 / 搜索量 / CVR / 竞争 / 核心词根 / 壁垒 / 预期效果 / 优先级
- 从20个壁垒中筛选最具蓝海潜力的方向
- 给出搜索量、CVR、竞争度、核心词根、壁垒说明、预期效果

## 执行顺序

### Step 1：读取三类数据源
确认：
- sheet 数与命名
- 字段名（评价文本列、品牌列、关键词列等）
- 数据量与样例

### Step 2：数据清洗
- 去除空行、重复评价
- 统一品牌/店铺名称
- 标准化价格、销量等数值字段

### Step 3：词频与需求提取
- 评价文本分词 → 提取痛点词、正面词、决策词
- 问大家问题分类 → 按决策阶段归类
- 搜索词排序 → 按搜索量/竞争度分级

### Step 4：12维需求矩阵构建
- 将提取的需求按12维归类
- 交叉评价×问大家×搜索词，计算综合优先级
- 生成"核心需求词"和"标题词根建议"

### Step 5：按6-Sheet结构落地
严格按"各 Sheet 详细规范"生成每个Sheet，注意：
- 保留分段式模块化结构
- 必须有分节标题
- 数据行必须交替底色

### Step 6：质量校验
至少检查：
- Sheet数是否为6个
- 每个Sheet第1行是否有大标题
- 表头样式是否正确（深绿底白字）
- 数据行是否有交替底色
- 优先级和竞争评级是否带emoji

## 技术执行细节

- Windows下优先：先读取参考示例的sheet名、行列数、合并单元格、列宽、颜色
- 脚本需支持命令行参数传入文件路径
- 如果字段名与预期不符，脚本应有探测逻辑（如通过关键词匹配列名）
- 如果某类数据缺失，脚本应生成带说明的占位行，而不是报错退出

## 注意事项

1. 不要把这类任务误做成普通词频表或纯评价汇总表。
2. 不要只做前几张基础表就结束，必须完整输出6个Sheet。
3. 不要忽略"差异化壁垒与蓝海策略"Sheet，这是最终收束到经营决策的关键。
4. 数据质量直接影响分析结果，清洗步骤不可省略。
5. 品类差异可能导致12维需求的具体内容需要调整，但框架保持不变。
6. 输出前务必进行数据校验，确保样式与参考示例高度对标。
7. 如本地脚本因中文/emoji/引号报错，不要停在中间状态，应立刻换更稳的方式继续做。
