# 小红书营销方案生成

## 输入

商品标题、主图或产品图（推荐）、详情页、SKU/参数、价格、目标人群、使用场景、品牌语气和平台限制。用户直接上传的图片优先作为产品锚点；只有用户提供路径时才读取该路径，不探测未授权的私有目录。

## 工作流程

1. 从商品资料和图片中提取产品事实、核心卖点、人群需求、使用场景、购买顾虑和可证明的差异点；未知信息标为待确认。
2. 设计 2–3 个笔记角度，分别给出标题、开头、正文结构、互动问题、标签和合规风险。
3. 根据笔记结构规划配图：首图、场景图、卖点图、细节图、对比/步骤图和收尾图。每张图说明目的、主体、构图、文字安全区和资产角色。
4. 输出可直接交给当前宿主图像工具的完整中文提示词。宿主支持时可选择 GPT Image、Banana/Nano Banana 等模型；本技能不负责调用具体软件。
5. 宿主有图像工具时，按图序执行并记录素材、参数、输出位置和质检结果；宿主没有图像工具时，交付完整提示词、素材清单、脚本和验收清单，不声称配图已生成。

## 输出结构

商品事实与风险边界、笔记定位、标题备选、正文、标签、配图总览、每张图完整提示词、发布前检查清单和待确认项。
