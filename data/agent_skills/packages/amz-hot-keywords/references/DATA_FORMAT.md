# 数据格式规范

## 脚本原始输出（JavaScript 提取）

脚本通过 Selenium 执行 JavaScript 从 AMZ123 页面提取的原始数据结构：

```json
{
  "word": "dog bed",
  "currentRank": 318,
  "lastRank": 288
}
```

---

## 格式化后数据（写入表格 / CSV）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| 搜索词 | 文本 | 亚马逊热搜关键词 | `dog bed` |
| 本周排名 | 数字 | 当前周在搜索结果中的排名（数字越小越靠前） | `318` |
| 上周排名 | 数字 | 上周排名，`0` 表示新上榜 | `288` |
| 涨跌幅度 | 单选 | 排名变化方向，取值：上升 / 下降 / 持平 | `下降` |

### 示例表格

| 搜索词 | 本周排名 | 上周排名 | 涨跌幅度 |
|--------|---------|---------|---------| 
| dog bed | 1 | 2 | 上升 |
| dog bed queen size | 5 | 3 | 下降 |
| orthopedic dog bed | 10 | 10 | 持平 |
| dog bed ramp | 15 | 0 | 上升 |

---

## 涨跌幅度计算规则

排名数字越小 = 排名越靠前（第 1 名优于第 2 名）。

| 条件 | 涨跌幅度 | 说明 |
|------|---------|------|
| 上周排名为 0 或空 | 上升 | 新上榜 |
| 本周排名 < 上周排名 | 上升 | 排名进步 |
| 本周排名 > 上周排名 | 下降 | 排名退步 |
| 本周排名 == 上周排名 | 持平 | 无变化 |

---

## CSV 输出格式

文件名：`hotwords_<keyword>_<timestamp>.csv`

```csv
搜索词,本周排名,上周排名,涨跌幅度
dog treats,123,124,上升
dog eye drops,221,416,上升
dog food,245,229,下降
```

## 通用表格 AI 表格字段映射

| CSV/JSON 字段 | AI 表格字段类型 | 备注 |
|---------------|---------------|------|
| 搜索词 | 文本 | — |
| 本周排名 | 数字 | — |
| 上周排名 | 数字 | 0 表示新上榜 |
| 涨跌幅度 | 单选 | 选项必须为：上升、下降、持平 |

> ⚠️ 涨跌幅度是**单选类型**，不能写入自由文本，必须是预设的三个选项之一。
