# 亚马逊热搜词分析技能包

根据产品关键词抓取多个亚马逊站点的热搜词，并输出可审计的 CSV、JSON 和 Markdown 结果。数据抓取、清洗、排名变化计算和文件保存由包内脚本负责；表格展示或后续分析由当前宿主决定。

## 快速开始

```bash
python scripts/amz123_enhanced_scraper_v2.py --keyword "dog bed" --storage csv
```

默认输出到当前工作目录下的 `./outputs` 或脚本指定的输出目录。需要结构化交接时，可选择 JSON 存储模式；宿主没有表格工具时，直接使用生成的 CSV/JSON 文件。

## 运行原则

- 先确认关键词、站点和结果条数，再执行抓取。
- 原始数据与清洗后数据分开保存，记录抓取时间和来源页面。
- 只报告脚本真实返回的结果，不补写不存在的排名或链接。
- 站点访问失败时保留已成功站点的数据，并清楚列出失败站点。

## 依赖

Python、脚本声明的公开依赖以及当前宿主可选的浏览器/网络能力。技能不依赖私有 宿主工具协议、账号、特定表格产品或固定域名。
