# 亚马逊热搜词分析｜使用教程

## 1. 这项技能做什么

亚马逊多站点热搜词抓取与分析技能 - 支持美国、法国、墨西哥、英国、德国、意大利、西班牙、加拿大、日本共 9 个站点。支持按产品关键词搜索亚马逊热搜词（如搜索"艾草锤""dog bed"等任意产品词），从 AMZ123 抓取与该关键词相关的热搜词列表及排名数据（搜索词、本周排名、上周排名、涨跌幅度），通过 `?k=关键词` 路径搜索，每页最多 200 条结果。默认美国站，美国站找不到数据时自动遍历其他 8 个站点。默认 CSV 本地管理。适用场景：跨境电商选品调研、亚马逊关键词分析、竞品热搜词监控。

## 2. 什么时候使用

当你的任务与「亚马逊热搜词分析」的名称、简介或触发范围一致时使用。

## 3. 使用前准备

1. 打开对话并直接说明目标。
2. 按需要提供商品名称、关键词、链接、图片、表格或其他原始资料。
3. 明确平台、国家/站点、数量、价格、时间范围等限制条件。
4. 如果资料不完整，先让技能列出缺失信息，再继续执行。

## 4. 对话步骤

1. 先说「请使用亚马逊热搜词分析」。
2. 说明你要解决的问题和最终想要的输出格式。
3. 一次性提供已知资料，并标注哪些内容可以推断、哪些内容必须以事实为准。
4. 检查初稿；需要修改时直接指出要调整的字段、范围或标准。

## 7. 注意事项

- 不要把示例中的商品、价格、供应商或数据当作真实结果。

- 涉及图片、文件或链接时，请确保已成功上传或提供完整地址。
