# Excel文件处理｜使用教程

## 1. 这项技能做什么

在任何以电子表格文件作为主要输入或输出的场景中，都应使用本技能。具体而言，这包括用户希望执行以下操作的任何任务：打开、读取、编辑或修复现有的 .xlsx、.xlsm、.csv 或 .tsv 文件（例如，添加列、计算公式、设置格式、绘制图表、清洗杂乱数据）；从头创建新电子表格或从其他数据源生成电子表格；或在表格文件格式之间进行转换。尤其当用户通过文件名或路径引用电子表格文件时（即使只是随口一提，比如“我下载文件夹里的那个 xlsx”），并且希望对其执行某些操作或从中生成某些内容时，就应触发本技能。同时，也适用于将混乱或结构不规范的表格数据文件（如格式错误的行、错位的表头、无效数据）清洗整理为规范电子表格的场景。交付物必须是电子表格文件。如果主要交付物是 Word 文档、HTML 报告、独立的 Python 脚本、数据库管道或 Google Sheets API 集成，即使涉及表格数据，也不应触发本技能

## 2. 什么时候使用

当你的任务与「Excel文件处理」的名称、简介或触发范围一致时使用。

## 3. 使用前准备

1. 打开对话并直接说明目标。
2. 按需要提供商品名称、关键词、链接、图片、表格或其他原始资料。
3. 明确平台、国家/站点、数量、价格、时间范围等限制条件。
4. 如果资料不完整，先让技能列出缺失信息，再继续执行。

## 4. 对话步骤

1. 先说「请使用Excel文件处理」。
2. 说明你要解决的问题和最终想要的输出格式。
3. 一次性提供已知资料，并标注哪些内容可以推断、哪些内容必须以事实为准。
4. 检查初稿；需要修改时直接指出要调整的字段、范围或标准。

## 5. 市场详情中的使用说明

详情页没有返回单独的使用教程；请以技能包内的 SKILL.md 为准。

## 6. 预期输出

技能通常会根据输入资料给出分析、清单、方案、表格或执行建议。输出类型以本技能包内 SKILL.md 的规则为准。

## 7. 注意事项

- 不要把示例中的商品、价格、供应商或数据当作真实结果。
- 需要实时平台数据时，应明确要求技能查询，并核对返回时间与来源。
- 涉及图片、文件或链接时，请确保已成功上传或提供完整地址。
- 版本：1.0.0；技能包路径：51-Excel文件处理/技能包

## 跨平台说明

本教程适用于小美宿主工作区、Codex 及其他支持 AgentSkills 的宿主。技能不绑定特定 CLI、宿主工具协议、账号或保存目录；输出默认使用当前工作目录下的 `./outputs`，也可按用户指定路径保存。宿主没有图片或视频工具时，照常交付完整提示词、脚本、素材清单和质检清单。
