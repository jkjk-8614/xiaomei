# 岗位配置：AIGC视觉设计师

**公司背景**：服务电商企业客户，专注于AIGC视觉解决方案创新与应用 
**核心使命**：探索AIGC在电商各行业的视觉应用潜能，为客户定制顶尖的电商视觉方案

---

## 评分维度与权重

| 维度 | 满分 | 说明 |
|------|------|------|
| 设计基础能力 | 40 | 作品集质量、设计经验、技能广度、创意表达 |
| AIGC认知潜力 | 30 | AIGC应用、工具了解、学习意愿 |
| 学习适应能力 | 20 | 职业转型、技能成长、项目多样性 |
| 综合背景 | 10 | 学历专业、工作稳定性 |

---

## 各维度打分细则

### 设计基础能力（0-40分）

| 情况 | 得分 | 评分逻辑 |
|------|------|----------|
| **作品集质量优秀**：≥3个完整商业案例，视觉专业，可直接用于客户提案 | 13-15 | 作品集描述含"商业案例"+"高保真"+"专业"等词 |
| **作品集质量良好**：1-2个商业案例或多个高质量练习作品 | 10-12 | 作品集描述含"商业案例"或"高质量练习作品" |
| **基础设计能力具备**：作品多为练习或内部项目，质量一般 | 7-9 | 作品集均为练习作品，质量描述一般 |
| **作品集薄弱**：作品集简单，设计基本功不足 | 4-6 | 作品集描述简单或无具体信息 |

| **设计经验资深**：3年以上电商/品牌/平面设计经验，有完整项目经历 | 8-10 | 相关设计经验年限≥3年 |
| **设计经验有积累**：1-3年相关设计经验，有项目积累 | 5-7 | 相关设计经验年限≥1年 |
| **设计经验新手**：1年以内经验或相关实习经历 | 2-4 | 相关设计经验年限>0 |

| **技能广度良好**：掌握多种设计工具（Figma/PS/AI等），有额外技能（动效/3D/设计系统） | 6-8 | 设计工具数量×1.5+额外技能加分 |
| **技能基础具备**：掌握基本设计工具，无额外技能 | 3-5 | 设计工具数量×1.5 |

| **创意表达突出**：作品有独特创意和视觉冲击力，有获奖或比赛作品 | 6-7 | 作品集描述匹配["独特创意","视觉冲击","创新设计","获奖作品"]≥2词 |
| **创意表达良好**：作品有创意亮点，能清晰表达设计理念 | 4-5 | 作品集描述匹配创意关键词=1词 |
| **创意表达一般**：作品创意普通，缺乏独特性 | 2-3 | 作品集描述未匹配创意关键词 |

### AIGC认知潜力（0-30分）

| 情况 | 得分 | 评分逻辑 |
|------|------|----------|
| **AIGC深度应用**：作品集有AIGC应用案例，AIGC在项目中起关键作用 | 10-12 | 作品集明确包含AIGC作品，且描述显示AIGC是关键产出 |
| **AIGC核心应用**：AIGC作为核心工具之一，有实际项目应用 | 7-9 | 作品集包含AIGC作品，AIGC是重要工具 |
| **AIGC尝试应用**：简单使用AIGC工具，无深度应用 | 4-6 | 作品集包含AIGC作品，但应用简单 |
| **仅有AIGC兴趣**：简历提及AIGC兴趣但无实际作品 | 1-3 | 简历提及AIGC兴趣但作品集无相关作品 |

| **工具了解广泛**：熟悉多种AIGC工具（SD/MJ/DALL-E/ChatGPT等） | 8-10 | 简历提及AIGC工具数量≥3 |
| **工具了解多种**：了解2种以上AIGC工具 | 5-7 | 简历提及AIGC工具数量=2 |
| **工具了解基础**：只知道基础AIGC工具 | 2-4 | 简历提及AIGC工具数量=1 |

| **学习意愿强烈**：明确表达AIGC学习计划，有探索案例 | 7-8 | 自我描述匹配["持续学习","探索AIGC","研究AI","AI课程"]≥2词 |
| **学习意愿积极**：对AIGC有兴趣，愿意学习 | 5-6 | 自我描述匹配学习关键词=1词 |
| **学习意愿一般**：基本兴趣表达，无具体计划 | 3-4 | 自我描述未匹配学习关键词 |

### 学习适应能力（0-20分）

| 情况 | 得分 | 评分逻辑 |
|------|------|----------|
| **强适应力**：有成功跨领域转型经历（平面→电商/UI→AIGC等） | 7-8 | 转型证据≥5分（平面→电商+3，UI→AIGC+3，跨行业+2） |
| **良好适应力**：有转型尝试，能适应新环境 | 5-6 | 转型证据≥2分 |
| **基本适应力**：工作类型稳定，无转型经历 | 3-4 | 转型证据<2分 |

| **持续成长**：简历显示多次新技能学习记录 | 6-7 | 技能更新次数≥2 |
| **有成长记录**：有过新技能学习经历 | 4-5 | 技能更新次数=1 |
| **基础成长**：有相关证书或培训经历 | 2-3 | 有证书或培训记录 |
| **成长有限**：无明确学习记录 | 0-1 | 无技能更新证据 |

| **项目多样性高**：服务多行业，项目类型多样 | 4-5 | 项目类型数×1+行业类型数×0.5≥4 |
| **项目多样性中等**：有一定项目变化 | 2-3 | 项目类型数×1+行业类型数×0.5≥2 |
| **项目多样性低**：项目类型单一 | 0-1 | 项目类型数×1+行业类型数×0.5<2 |

## 加分项（每项 +3，上限 +9）

- [ ] **跨领域设计能力**：有品牌+电商+平面等多领域经验
- [ ] **AIGC探索精神**：有AIGC学习笔记、作品尝试或相关研究
- [ ] **商业理解能力**：理解电商商业逻辑，能将设计与商业目标结合
- [ ] **技术好奇心**：主动关注新技术，有快速学习新工具的成功案例

## 岗位特有风险标记

**高风险**（满足任意一项需重点复核）：
- AIGC兴趣可疑：简历提到AIGC但作品集无任何相关作品
- 作品集与简历不匹配：简历经验丰富但作品集简单
- 技能夸大嫌疑：列出大量工具但作品集未体现
- 职业路径混乱：工作方向频繁变动无逻辑

**优势信号**（满足可适当加分）：
- 真实项目经验：有知名品牌或完整电商全案
- AIGC深度应用：AIGC在项目中起关键作用
- 成功转型案例：明确跨领域成功转型经历
- 持续学习记录：有证书、培训、比赛获奖
