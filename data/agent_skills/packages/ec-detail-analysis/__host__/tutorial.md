# 详情页分析｜使用教程

## 1. 这项技能做什么

分析淘宝/天猫详情页图片、长图、截图和商品卖点信息，区分竞品/Top页面拆解与自家页面诊断，自动识别参考页类目、我方产品信息和迁移深度，并输出可交给详情页生成 skill 使用的生成用策划摘要。用于用户上传行业Top、竞品、标杆、自家详情页时，从商家视角提炼可迁移打法、卖点表达、用户认知、购买欲、图文节奏、改版方向，并在分析后询问是否继续策划生成详情页

## 2. 什么时候使用

当你的任务与「详情页分析」的名称、简介或触发范围一致时使用。

## 3. 使用前准备

1. 打开对话并直接说明目标。
2. 按需要提供商品名称、关键词、链接、图片、表格或其他原始资料。
3. 明确平台、国家/站点、数量、价格、时间范围等限制条件。
4. 如果资料不完整，先让技能列出缺失信息，再继续执行。

## 4. 对话步骤

1. 先说「请使用详情页分析」。
2. 说明你要解决的问题和最终想要的输出格式。
3. 一次性提供已知资料，并标注哪些内容可以推断、哪些内容必须以事实为准。
4. 检查初稿；需要修改时直接指出要调整的字段、范围或标准。

## 6. 预期输出

技能通常会根据输入资料给出分析、清单、方案、表格或执行建议。输出类型以本技能包内 SKILL.md 的规则为准。

## 7. 注意事项

- 不要把示例中的商品、价格、供应商或数据当作真实结果。
- 需要实时平台数据时，应明确要求技能查询，并核对返回时间与来源。
- 涉及图片、文件或链接时，请确保已成功上传或提供完整地址。
- 版本：1.0.1；技能包路径：33-详情页分析/技能包

## 跨平台说明

本教程适用于小美宿主工作区、Codex 及其他支持 AgentSkills 的宿主。技能不绑定特定 CLI、宿主工具协议、账号或保存目录；输出默认使用当前工作目录下的 `./outputs`，也可按用户指定路径保存。宿主没有图片或视频工具时，照常交付完整提示词、脚本、素材清单和质检清单。
