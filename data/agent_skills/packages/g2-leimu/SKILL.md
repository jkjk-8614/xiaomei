# G2-自己店铺·类目链接明细拆解

通用类目技能。根据输入的生意参谋商品排行CSV，按一级类目拆解生成类目索引+各类目明细Sheet。技能不绑定特定类目，自动识别CSV中的类目字段。

**用法:**
```bash
python build_G2.py --input "数据.csv" --output "输出目录" --shop-name "店铺名"
```

**注意:** 生成的产物内容需严格和技能中的参考示例对标。

## 一、技能信息

| 项目 | 内容 |
|:---|:---|
| **技能编号** | G2 |
| **技能名称** | 类目链接明细拆解 |
| **所属阶段** | G2-自己店铺 |
| **核心数据源** | 自己店铺数据 |
| **输出格式** | Excel |

## 二、分析思维

将店铺链接按类目拆解:旅行箱/其他家具/赠品，形成类目索引

## 三、呈现逻辑

4Sheet:类目索引→旅行箱→其他家具→赠品

技能脚本依赖 `pandas` + `openpyxl`，确保当前环境已安装：

**参数说明：**
