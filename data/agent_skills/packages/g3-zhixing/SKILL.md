# G3-自己店铺·执行报告生成总览

通用技能。根据G1/G2生成的Excel或生意参谋原始CSV，生成功率汇报PPT。支持分阶段生成：P0核心10页（店铺诊断）→ P1完整38页（全链路闭环）。

**用法:**
```bash
python build_G3.py --g1-input "G1报告.xlsx" --g2-input "G2报告.xlsx" --output "输出目录" --shop-name "店铺名"
# 或直接从CSV生成
python build_G3.py --csv-input "生意参谋数据.csv" --output "输出目录" --shop-name "店铺名"
```

**注意:** 生成的产物内容需严格和技能中的参考示例对标。

## 四、执行步骤

### Step 1: 确认 Python 环境
技能脚本依赖 `pandas` + `python-pptx`，确保当前环境已安装：
```bash
pip install pandas python-pptx
```

### Step 2: 执行脚本
脚本位于技能目录下，使用绝对路径调用：
```bash
python "<当前用户工作目录> Skill 宿主\.通用 Skill 宿主\user-skills\g3-zhixing\build_G3.py" \
  --csv-input "生意参谋商品排行.csv" \
  --output "D:\宿主\文档" \
  --shop-name "店铺名称" \
  --pages 38
```

**参数说明：**
| 参数 | 必填 | 说明 |
|:---|:---|:---|
| `--csv-input` | ✅ | 生意参谋商品排行CSV路径（与G1/G2同源） |
| `--g1-input` | ❌ | G1生成的Excel路径（可选，优先于csv） |
| `--g2-input` | ❌ | G2生成的Excel路径（可选） |
| `--output` | ❌ | 输出目录，默认 `D:\宿主\文档` |
| `--shop-name` | ❌ | 店铺名称，默认从文件名提取 |
| `--pages` | ❌ | 生成页数，默认38（完整版），最小10（P0核心） |

**完整示例：**
```bash
python build_G3.py \
  --csv-input "D:\宿主\下载\生意参谋\店铺名\商品\商品排行\智能选款_店铺名_全部标准类目_2026-06-29 ~ 2026-07-28.csv" \
  --output "D:\宿主\文档" \
  --shop-name "店铺名" \
  --pages 38
```

### Step 3: 检查输出
脚本运行后会输出完整文件路径，格式为：
