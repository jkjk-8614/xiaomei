# 画面视觉规范

视觉目标必须匹配成交心智，不统一追求“高级感”。

## 套图视觉统一

做5张主图时，先定一套视觉规范，再写单图 prompt。

必须统一：

- 品牌/品类DNA
- 色彩分组
- 字体、标签、图标系统
- 光线方向和背景质感

允许变化：

- 每张图的销售任务
- 场景和视角
- 整体/局部/细节展示
- 主卖点和文案内容

不允许为了单张图好看，破坏整套图的品牌一致性。

## 成交心智与视觉方向


| 目标   | 视觉方向                |
| ---- | ------------------- |
| 审美标签 | 极致好看、风格强、氛围感、强记忆点   |
| 信任标签 | 真实、干净、清楚、不过度修饰      |
| 亲近感  | 生活化、有人味、自然光、有温度但不杂乱 |
| 性价比  | 信息清晰、利益点直接、画面有冲击    |
| 高客单  | 克制、留白、材质、光影、秩序      |
| 功能品  | 结构清楚、对比明显、图标辅助      |
| 食品   | 新鲜、分量、口感、真实质感       |
| 母婴健康 | 柔和、安全、可信、干净         |


## 主体与构图

- 产品主体占比通常 60%-80%，高端留白图可略低但小图仍清楚。
- 主体不能被遮挡。
- 重要卖点靠近视觉中心或明确的信息区。
- 背景不能抢主体。
- 搜索结果小图状态下仍能识别。
- 预留文字安全区，距边缘至少 5%-8%。

## 光影配方

- 高级感：柔和侧光、低对比、干净阴影、边缘高光清晰。
- 科技感：冷光、边缘光、干净渐变、金属/玻璃反光控制。
- 食品：自然光、暖色、真实质感、切面和汁水/纹理清晰。
- 家居：窗边自然光、生活化阴影、空间层次。
- 美妆：棚拍柔光、反光控制、质地清晰。
- 农产品：自然光、真实产地感、不过度精修。
