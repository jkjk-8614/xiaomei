# 字体与排版规范

电商主图默认需要文字。关键不是少写字，而是让一整套图的字体系统、字号层级、标点规则、标签样式和语气统一。

## 两种模式

### 内嵌文字模式

默认使用内嵌文字模式，除非用户明确要求无字，或文字准确性风险已经高到不适合模型直出。

适合：

- 字数短
- 字形不要求绝对准确
- 模型中文能力较好
- 用户愿意后期微调

必须写清：

- 文字内容
- 字体风格
- 主副标题层级
- 字号比例
- 字色
- 位置
- 与产品距离
- 描边/阴影/底色/标签框

同时必须统一：

- 全套主标题字体系统一致。
- 全套副标题字体系统一致。
- 主标题默认不加句号，尽量不用逗号。
- 主标题不要加中文引号、书名号、装饰括号；除非用户文案本身明确要求。
- 标签控制在4-6个字以内。
- 同一套图的字号、字重、标点和语气一致。
- 小字超过10个字时，优先缩短文案或拆成短标签；仍过长时再追加后期排版备选。
- lookbook、鞋服、家居、香氛等审美驱动图，主标题要克制，避免压过画面氛围。

### 后期排版模式

适合：

- 中文必须准确
- 字数较多
- 有品牌字体规范
- 需要平台审核安全
- 需要强信息表达

prompt 写法：

- 不生成任何文字
- 预留左上/右侧/底部信息区
- 背景干净
- 保留足够对比度
- 输出后期字体规范

后期排版只作为备选或用户指定方案，适合：

- 3C参数、规格、兼容说明较多。
- 食品、母婴、健康、美妆等需要严谨功效/产地/认证表述。
- 用户明确说要商用、上架、投放或必须逐字准确。
- 用户提供品牌字体、固定标题或法务审核文案。
- AI内嵌中文已经出现机器字、错字、乱码或风格不统一。

即使建议后期排版，也应先给默认带文字主图方案，除非用户明确说不要文字。

## 字体风格选择

| 商品调性 | 字体方向 |
|---|---|
| 高端感 | 细黑体、宋体、衬线字体、克制字重 |
| 科技感 | 几何无衬线、数字感字体、冷色系 |
| 食品/农产品 | 圆润黑体、手写感、质朴但清楚 |
| 母婴 | 圆角字体、柔和、低攻击性 |
| 家居 | 现代黑体、轻奢衬线、简洁无衬线 |
| 潮流服饰 | 粗黑体、复古字体、街头字体 |

## 信息层级

- 主标题：最大、最醒目，建议短。
- 副标题：解释卖点。
- 标签：辅助记忆点。
- 参数：小号但清楚。
- 信任背书：稳定、克制。

## 可读性规则

- 主标题不要太长。
- 主标题不要过大；审美品先保留画面呼吸感，再保证文字可读。
- 小图状态下仍能看清关键字。
- 对比度足够。
- 不压产品主体。
- 不贴边。
- 不被复杂背景干扰。
- 标签数量不能太多。
- 中文准确性优先时，可以追加后期排版备选。
- 需求式画面 prompt 不等于文字自由发挥；文字内容、字体、标点和层级仍要明确。
