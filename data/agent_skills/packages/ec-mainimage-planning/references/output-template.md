# 输出模板

完整内容写入 Markdown 文件。对话框只返回文件路径，并询问用户是否要修改或继续生图。

默认输出中文生图提示词。除模型命令、固定参数、必要摄影/风格术语外，不输出整段英文 prompt。画面内文案默认中文。

## 0.1 生图设置确认

默认设置要直接告诉用户。用户未指定时按默认执行；用户可以在确认生图前修改比例、模型或分辨率。

| 设置项 | 默认值 | 可选项/说明 | 当前采用 |
|---|---|---|---|
| 出图比例 | 1:1 | 可选 3:4，或用户指定比例 |  |
| 生图模型 | Nona banana pro | 可选 GPT image 2，或用户指定模型 |  |
| 出图分辨率 | 1K | 可选 2K，或用户指定分辨率 |  |
| 文案模式 | 内嵌中文文字 | 可改无字底图/后期排版/双版本 |  |

模型、比例、分辨率可以混合选择；例如 Nona banana pro + 3:4 + 1K，或 GPT image 2 + 1:1 + 2K。

提示用户可选择：

```text
默认按 1:1、Nona banana pro、1K 生成。也可以混合选择 GPT image 2、3:4、2K，或指定其中任意一项。
```

### 3.6 系列统一 prompt 继承块

这一块不是固定文案。必须根据当前产品、商品资料、参考图和本次启用的视觉控制维度，生成一段“本项目专属”的系列统一块。

生成规则：

- 只生成一版，作为 5 张主图共同继承的视觉母版。
- 必须写具体，不要保留“品牌/品类DNA、色彩分组”等泛词。
- 必须包含本商品的品类气质、产品颜色/材质、色彩家族、字体/标签风格、光线和安全区。
- 可以包含弹性边界，例如“背景可在浅暖灰和深焦糖之间变化，但都保持低饱和复古质感”。
- 不要写死单图场景、单图道具、单图卖点；这些放到每张图自己的提示词里。
- 5 张主图的完整提示词都要复制同一段 `【系列统一】`，不要写“同上”。

```text
【系列统一】
这5张图属于同一套[平台/品类]主图，整体气质统一为[本商品专属品牌/品类气质]；产品必须保持[本商品颜色、材质、结构、关键识别点]一致；画面使用[本项目色彩家族和分组规则]，文字使用[本项目中文字体/标签/图标风格]，光线保持[本项目光线语言]，背景保持[本项目背景质感边界]，保留[本项目留白和文字安全区规则]。允许[本项目可弹性变化项]随主图任务变化，但不得出现[本项目禁止项]。
```

输出时必须把方括号内容替换成当前项目的具体内容。系列统一块只写锁定规则和必要弹性边界；具体场景、视角、道具和单图卖点放进每张图的本图段落，不要把每张图写成完全相同。

## 4. 参考图/竞品图转译

| 元素 | 本次怎么借鉴/转译 | 不借鉴或需改写什么 | 用于哪张主图 | 来源 |
|---|---|---|---|---|
| 构图/视角 | 例如镜头距离、主体位置、留白比例、低/平/俯视角 | 如不需要，排除参考图人物姿势、原产品摆位、原背景关系 |  |  |
| 光影/色调 | 例如明暗关系、光线方向、冷暖氛围、胶片感 | 如不需要，改写参考图完整配色、环境光和色彩组合 |  |  |
| 人物/服装/姿态 | 例如人群状态、穿搭调性、动作能量、上脚/上身姿态 | 不复制具体人物长相、具体衣服款式、参考图中的鞋/产品 |  |  |
| 道具/场景/背景 | 例如场景类型、生活方式氛围、空间层次 | 不复制具体道具、墙面、街景、家具、品牌露出 |  |  |
| 字体/版式 | 例如信息层级、标题大小关系、标签节奏 | 不复制品牌、原文案、logo、促销信息 |  |  |
| 竞品信息表达 | 例如表达结构、小图可读性、卖点分层方式 | 不复制竞品事实、认证、参数和商品图 |  |  |

参考图使用规则：

- 参考图/竞品图不是产品锚点图。
- 使用参考图的单图，也必须同时指定产品锚点图。
- 不要写“参考图风格”这种空泛指令；必须写成“参考图用于借鉴[本图需要的具体元素]，[不需要的元素]不要自动带入或需要改写”。
- 如果参考图里有人物、鞋、服装、道具或其他商品，先按本图策划判断哪些元素有价值；有价值的可以转译，没被明确选中的不要默认带入。
