# 参考图转译规则

不要写“按参考图一样生成”。要明确借鉴什么，不借鉴什么。

## 主图套图转译

如果参考输入是一套自家现有主图或竞品5张主图，不要只看单张风格。先转译“套图结构”：

| 可转译 | 不可照搬 |
|---|---|
| 图序分工：哪张负责点击、哪张负责信任、哪张负责顾虑回应 | 竞品品牌、认证、商品结构、参数、功效、文案 |
| 信息层级：大标题、标签、利益点、辅助说明的层级 | 竞品原图素材、人物、场景、包装、logo |
| 构图节奏：产品占比、留白、安全区、文字位置 | 和本商品不符的材质、卖点、价格、服务承诺 |
| 小图可读性：文字数量、对比度、主体清晰度 | 可能造成混淆或侵权的视觉元素 |

自家现有主图用于改版：保留有效资产，修复点击弱、重复卖点、文字拥挤、缺少顾虑回应等问题。

竞品主图用于策略启发：只借鉴“为什么这样安排有效”，不要复制“它具体写了什么、长什么样”。

## 转译句式

```markdown
借鉴参考图的[低饱和暖灰色调、柔和侧光、大面积留白、细黑体标题系统]，但产品主体严格保持为用户上传商品图中的产品，不借鉴参考图中的产品形态、材质、结构或装饰元素。
```

## 借鉴范围

- 色调
- 光影
- 构图
- 留白
- 字体系统
- 图标样式
- 标签样式
- 高级感/亲近感/促销感
- 生活方式氛围
- 画面节奏
- 情绪气质

## 视觉继承强度

先判断参考图对本次输出的约束强度，不要一律只“轻微借鉴”。

| 强度 | 适用场景 | 输出要求 |
|---|---|---|
| 强继承 | 用户给的是同品类/目标风格参考，尤其鞋服、家居、香氛、美妆等审美驱动品 | 必须继承参考图的构图逻辑、人物裁切、光线、留白、文字密度和情绪，不得退化成普通详情页模板 |
| 中继承 | 参考图只提供某些局部方向，如光影、字体、色调、标签 | 继承指定视觉元素，其余按商品和平台调整 |
| 弱继承 | 参考图只是反例、随手图或跨品类气质参考 | 只吸收抽象气质，不绑定构图 |

鞋服/lookbook 类参考图通常应强继承视觉语言：人物姿态、低机位、白袜/腿部裁切、街头/球场氛围、少字留白，是视觉目标的一部分。即使要表达增高、舒适、材质，也不能把主图2-5全部变成参数页、细节卡或详情页模板。

## 输入图角色分配

把输入图片分配角色，再写 prompt：

| 输入类型 | 主要作用 | 不能越界 |
|---|---|---|
| 产品图/白底图 | 锁定产品事实、结构、颜色、比例、材质视觉 | 不负责定义最终风格，除非没有参考图 |
| 参考图/风格图 | 锁定视觉语言、光影、构图、人物裁切、文字密度、情绪 | 不借鉴产品结构、品牌、logo、错误品类元素 |
| 包装图/SKU图 | 锁定品牌、包装、口味/规格/SKU识别 | 不应默认每张都作为主视觉 |
| 场景图/详情页图 | 锁定使用想象、道具、场景可信度 | 不把场景辅助物画成商品赠品 |
| 评价/文字资料 | 锁定卖点、顾虑、语言方向 | 没有证据的强背书不能直接上图 |

## 参考图避免被模板吞掉

当参考图是品牌大片、lookbook、生活方式图时：

- 保留低文字密度，不要把每张都做成大标题+参数卡。
- 保留人物裁切和姿态，不要只剩商品棚拍。
- 保留光线和留白，不要塞满标签和圆形细节框。
- 卖点可以轻量嵌入，但不能破坏参考图的视觉语言。
- 主图2/3/4即使说明功能，也要保持同一视觉家族。

## 不借鉴范围

- 参考图里的产品结构
- 错误品类元素
- 错误场景
- 不适合本品类的信息密度
- 不适合目标平台的表达方式
- 不适合价格带的视觉气质
- 参考图品牌、logo、文字

## 输出格式

```markdown
## 参考图转译
- 参考图类型：
- 视觉继承强度：强/中/弱，以及原因
- 输入图角色分配：
- 可借鉴：
- 不借鉴：
- 转译到本商品：
- 写入 prompt 的约束句：
```
