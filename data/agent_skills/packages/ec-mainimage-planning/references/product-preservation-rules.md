# 产品保持与事实边界

产品保持是图生图的第一优先级。不要为了风格牺牲产品真实。

## 产品保持指令

图生图 prompt 必须包含：

```markdown
【产品保持】
严格参考输入产品图，只改变背景、光线、场景与排版空间；产品主体的外形、比例、颜色、结构、材质视觉特征、包装原有文字和图案保持不变。不新增按钮、接口、配件、花纹、logo，不改变商品数量，不拉伸、不扭曲、不变胖、不变薄，不遮挡关键结构。
```

## 错误精确词规则

能确认的写具体，不能确认的写宽泛；看图可见的用“如图”锚定。

| 不确定时不要写 | 安全写法 |
|---|---|
| 实木靠背 | 保持如图靠背材质与纹理，不改变颜色、结构和表面质感 |
| 304不锈钢框架 | 保持如图金属质感框架，颜色、粗细、连接结构不变 |
| 真皮 | 保持如图皮质/革面视觉质感，不改变纹理和颜色 |
| 无添加/抗菌/认证 | 预留文案区，待用户确认真实资料后添加 |
| 品牌 logo 清晰 | 保持包装上的原有文字和图案，不新增、不改写、不替换 |

## 禁止编造

除非用户明确提供证据，否则不要写：

- 具体材质等级
- 承重数值
- 功效保证
- 检测认证
- 产地背书
- 品牌授权
- 兼容型号
- 医疗/健康效果
- 不存在的配件

## 辅助物与包装角色

图生图中，辅助物、包装和道具必须说明角色，避免模型误读。

- 包装图可以作为品牌/SKU锚点，但不要默认每张都强中心出现。
- 多口味/多SKU包装组合只在需要说明规格、口味、选择或品牌阵列时作为主视觉。
- 场景里的电脑、手机、线材、餐具、食材、桌椅、人物服装等是辅助物，不表示随商品附带。
- 食品包装文字、品牌logo、SKU口味名容易变形；商用前必须复核。
- 强背书文字，如认证、检测、国标、无抗、产地、营养数值，必须来自用户确认或可见资料；只有口述但无证明时标为待确认文案。

prompt 可加入：

```markdown
输入包装仅作为品牌/SKU识别，不要求每张都出现；若出现，按本图任务决定是主视觉还是角落辅助。场景道具仅用于使用氛围，不表现为商品赠品。所有认证、检测、营养数值和规格参数只使用已确认信息。
```

## 参考图强继承时的产品锁定

参考图可以强继承构图、光线、人物裁切、文字密度和情绪，但不能强继承参考图里的产品形态。

prompt 应明确：

```markdown
参考图只用于视觉语言，不用于重绘商品结构。商品外形、比例、颜色、材质视觉和关键结构以输入产品图为准；即使参考图视觉强继承，也不能让参考图中的产品形态或品牌装饰影响当前商品。
```

## 品类易错保持规则

| 品类 | 容易错 | 必须强化 |
|---|---|---|
| 3C数码配件 | 新增/省略接口，改变端口形状，把辅助线材画成赠品，参数乱写 | 保持接口数量、位置、形状、线材连接方式；不新增配件；参数只写已确认信息 |
| 鞋服 | 改鞋型、改颜色、改鞋底厚度、左右脚比例异常、logo变形 | 保持鞋型、鞋面结构、颜色、鞋底厚度、logo/装饰位置；上脚场景也不改变产品 |
| 家具 | 改靠背/扶手/椅腿结构，材质误判，比例失真 | 保持轮廓、比例、连接结构、纹理和材质视觉；尺寸/承重未确认不写死 |
| 食品/农产品 | 包装文字变形，分量夸张，功效/产地编造，食材状态过度美化 | 保持包装、数量和真实质感；产地、冷链、无添加、营养功效必须有证据 |
| 美妆个护 | 包装文案/logo变形，功效承诺过强，成分编造 | 保持瓶身/盒身文字图案；功效、成分、认证未确认只预留文案区 |

## 3C接口专项指令

3C扩展坞、转接器、充电器等 prompt 必须额外加入：

```markdown
不新增、不省略、不改造任何接口、孔位、按钮、线材和卡槽；接口数量、形状、位置、间距严格参考输入产品图。电脑、手机、线材、存储卡等只作为使用场景辅助，不表现为商品赠品。所有参数、协议、兼容型号只使用用户已确认或商品图可见信息。
```

## 输出摘要

每次 prompt 前输出：

```markdown
## 产品保持摘要
- 必须保持：
- 可以调整：
- 不可确认，避免写死：
- 易变形风险：
```
