# 提示词生成决策流程

按以下顺序执行。

## 1. 读取输入

- 如果有 strategist 报告，优先读取 `generator_brief`。
- 如果 brief 里有 `evidence_map`、`avoid_claims`、`copy_mode_recommendation`、`category_specific_constraints`，必须继承到提示词。
- 如果没有报告，读取用户商品图、商品描述、参考图和需求，做轻量策略判断。
- 如果有产品图，先分析图，不要先写 prompt。

## 1.2 输入资产角色与使用节奏

先判断每个输入资产在套图中的角色。不要让最安全的素材反复占据全部画面。

| 资产 | 默认角色 | prompt 中要说明 |
|---|---|---|
| 产品图 | 产品事实锚点 | 哪些结构/颜色/比例/材质必须保持 |
| 参考图 | 视觉语言锚点 | 继承强度、构图、光线、文字密度、场景气质 |
| 包装图 | 品牌/SKU锚点 | 哪几张出现、是否主视觉、是否角落辅助 |
| 肉质/材质/细节图 | 质感证明 | 哪张做主视觉，避免被包装挤掉 |
| 场景图 | 使用想象 | 哪张承接场景，辅助物不表现为赠品 |

为每套5张图设定素材使用节奏：

- 包装/SKU组合图可以作为品牌锚点，但不要无意识地在多张图里重复强中心；先决定哪些图需要包装主视觉，哪些图只需辅助露出或不出现。
- 参考图为强继承时，保持构图、光线、人物裁切、文字密度和情绪，但不要让所有图都变成同一种场景。
- 食品类要在包装、口感/质地、食用场景、信任信息之间分配主次，不要只重复包装。
- 鞋服类要在上脚/穿搭、产品质感、鞋型/结构证明、顾虑回应之间分配主次，不要只有场景图。
- 3C类辅助电脑、线材、键鼠、卡片等只作场景，不表现为随商品附带。

## 1.5 选择提示词模式

先判断用哪种模式，不要默认一律详细分镜。默认主方案是带文字主图；无字底图不是默认主方案，只在用户指定或文字准确性风险过高时作为备选。

| 模式 | 适合场景 | 写法 |
|---|---|---|
| 需求式画面 brief + 内嵌文字 | 默认模式，适合 Banana Pro 等视觉推理强、需要生活方式感/高级感/自然氛围 | 给商业目标、产品保持、风格、人群、卖点、禁止项，少规定细碎构图；同时强约束字体系统和文案层级 |
| 半分镜式 + 内嵌文字 | 功能图、对比图、参数区、结构说明 | 规定区域、层级、产品占比、图标/标签逻辑，并保持全套字体统一 |
| 无字底图 + 后期排版 | 用户明确要求无字、品牌字体必须准确、长文案/参数多到模型难以稳定，或内嵌文字已失败 | prompt 明确不生成文字，只预留干净信息区；作为备选而非默认主方案 |
| 双版本 | 用户要商用高确定性，或想保留AI文字同时准备后期兜底 | 主版本仍为内嵌文字，备选版本为无字底图 |

经验规则：画面可需求式释放模型能力，文字必须强约束；默认全套带字且字体统一。后期排版是兜底，不是默认。

## 2. 产品图分析

输出产品保持摘要：

- 产品品类
- 主体轮廓
- 比例关系
- 主要颜色
- 材质视觉特征
- 关键结构
- 包装/Logo/文字
- 可见卖点
- 不可确认信息
- 容易被 AI 画错的部位

## 3. 事实边界

区分四类：

- 可见事实：图片里能看见。
- 用户确认事实：用户文字明确说了。
- 策略推断：可用于氛围、场景、风格，不当作硬事实。
- 禁止编造：认证、材质等级、功效、参数、品牌背书、产地等。

prompt 只能把前两类写成事实。策略推断只能用于视觉方向。

## 4. 销售任务判断

每张图先判断任务：

- 抢点击
- 强化标签
- 展示质感
- 解释功能
- 回应顾虑
- 建立信任
- 强化场景代入
- 做差异化记忆点
- 促成决策

没有销售任务的 prompt 容易生成好看的废图。

## 4.5 五图节奏矩阵

视觉统一不等于构图重复。5张图必须继承同一视觉家族，但承担不同转化角色。

默认节奏：

```text
抢点击 -> 建代入 -> 讲核心卖点 -> 解顾虑 -> 做收口
```

| 图序 | 节奏任务 | 用户问题 | 重点 | 画面感觉/常见主体资产 |
|---|---|---|---|
| 图1 | 抢点击 | 我为什么停下来？ | 商品第一眼、风格、核心利益点 | 最干净、最有识别度、信息不太满；产品大主体/强记忆点 |
| 图2 | 建代入 | 它适合我吗？我用它是什么感觉？ | 使用场景、人群状态、穿搭/使用效果 | 有场景感；上身/上脚/生活方式/使用结果 |
| 图3 | 讲核心卖点 | 它好在哪里？关键利益怎么被看见？ | 材质、功能、差异化优势 | 更聚焦产品；材质近景、结构证明、轻对比、功能场景 |
| 图4 | 解顾虑 | 我担心的问题解决了吗？ | 细节、对比、痛点回应、品质证明 | 更理性；局部放大、评价高频顾虑、适配/安全/耐用说明 |
| 图5 | 做收口 | 我现在为什么可以买？怎么选？ | 卖点总结、SKU/颜色/规格、购买理由 | 信息最完整但清楚不乱；SKU选型、组合、差异化总结 |

检查规则：

- 不允许5张都变成同一种场景图。
- 不允许5张都变成参数/详情页模板。
- 不允许5张都只讲卖点，没有点击、代入、顾虑和收口。
- 审美品参考图强继承时，图2/3/4也要保持同一光线、字体和留白，但必须承担产品确认、卖点证明、顾虑回应。
- 根据品类保留必要的产品确认/细节证明，不要只有情绪场景或只有参数说明。

## 5. 全局视觉母版

先建立一套母版，再写单图：

- 整体风格
- 主色调
- 辅助色
- 背景质感
- 光线方向
- 阴影风格
- 字体系统
- 图标风格
- 标签样式
- 产品占比范围
- 留白规则
- 平台适配
- 文字系统：字体、字号、字重、标点、层级、标签长度、语气、位置；整套必须统一
- 输入资产使用节奏：产品图、参考图、包装图、场景图分别在哪些图承担主视觉或辅助作用

## 6. 单图差异

5张图继承同一母版，只改变任务、场景和卖点表达。

每张 prompt 包含：

- 系列统一指令
- 销售任务
- 目标标签/目标人群/避免吸引
- 产品保持
- 画面主体
- 场景背景
- 构图视角
- 光影色彩
- 文案与排版
- 情绪与状态
- 负面 prompt
- 验收标准

每张 prompt 还要写清：

- 主体资产：产品/包装/上脚/肉质/场景/参数/细节。
- 转化角色：点击、产品确认、卖点证明、顾虑回应、决策收口。
- 参考图继承点：构图、光线、人物裁切、文字密度或情绪。
- 该张是否出现包装/辅助物；如果出现，是主视觉还是辅助。

## 7. 检查后输出

输出前检查：

- 产品是否可能被改形
- 是否用了错误精确词
- 5张图是否统一
- 每张图任务是否不同
- 是否符合平台和人群标签
- 文案是否准确可读
- 是否有虚假卖点
- 文字系统是否统一：字体、字号、字重、标点、语气、标签长度
- 参数/接口/结构是否改变，尤其3C、家具、鞋服、包装食品
- 输入输出是否顺承：产品图锁事实、参考图锁视觉、包装图锁品牌、场景图锁使用想象
- 是否过度重复某个输入素材，例如包装连续多张强中心
- 参考图是否被电商模板吞掉，尤其鞋服/审美品
- 五张图是否覆盖完整转化矩阵，是否有任务重复或缺少产品确认/细节证明
