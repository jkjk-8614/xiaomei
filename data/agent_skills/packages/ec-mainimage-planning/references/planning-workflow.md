# 主图策划工作流

## 1. 读取分析交接

优先读取 `主图分析.md` 末尾的“给主图策划的结构化交接”：

- `asset_manifest`
- `product_facts`
- `audience_and_labels`
- `pain_points`
- `selling_points`
- `risk_boundary`
- `reference_translation`
- `planning_notes`

如果没有结构化交接，从分析正文中提取同等信息，但要标记为“基于正文推断”。

如果没有 `主图分析.md`，不要因此中断。把当前输入当作独立策划任务处理：

1. 先快速归类资产。
2. 提取用户明确给出的品类、卖点、平台、风格偏好。
3. 把无法证明的卖点标为待确认。
4. 仍然输出 5 张主图策划和提示词，但把生图状态标为“产品图缺失/待上传”。

如果独立策划输入里包含 `.xlsx`、`.xls`、`.csv`、`.tsv`：

1. 先读取表格文件结构：sheet 名、行列规模、表头、关键列和样例行。
2. 判断表格角色：评价/问大家、SKU/参数、竞品卖点、用户调研或其他。
3. 把表格提炼出的痛点、卖点、参数和风险写入输入资产检查、主图执行总览和事实边界。
4. 如果表格无法读取，先标为风险，不要假装已经利用表格内容。

如果独立策划输入里包含自家现有5张主图或竞品5张主图：

1. 先判断归属：自家现有主图、竞品主图、待确认。
2. 按图序拆解每张图任务：点击、产品确认、信任、卖点证明、顾虑回应、场景、SKU/收口。
3. 自家主图用于找改版问题：首图弱、卖点重复、缺顾虑回应、字体不统一、小图不可读等。
4. 竞品主图用于策略转译：借鉴套图分工、信息层级、构图节奏，不复制竞品文案、商品事实、品牌和认证。
5. 在新五图方案中说明“参考了套图结构的哪一点、避开了哪一点”。

## 2. 输入资产检查

每次策划和生图提示词前都要确认产品事实锚点图：

- 已找到产品图/白底图/商品实拍图：继续，提示词中明确“严格参考输入产品图”。
- 找不到产品图：可以先输出策划和提示词，但生图前暂停，要求用户上传。
- 用户明确说没有产品图且接受文生图风险：可以继续，但在文件中标注产品一致性风险。

竞品图和参考图只用于对照/转译，不替代产品图。

## 2.1 参考图防误用

参考图的作用是按策划目的转译可用视觉元素，不是让模型无意识复制另一个画面。尤其是鞋服、家居、食品等品类，参考图里常常有人物、产品、服装、道具和场景；其中有些元素可能正是策划需要的，有些会干扰本商品。关键不是一刀切禁止，而是逐项判断并写清边界。

处理参考图时按下面规则写：

- 先判断参考图角色：构图参考、光影参考、字体版式参考、场景氛围参考、动作姿态参考、人物状态参考、服装调性参考、道具/背景类型参考、竞品信息层级参考。
- 按本图策划选择可用元素，例如“低机位街拍感”“左侧大留白”“暖调自然光”“标题大字+小标签结构”“松弛蹲姿”“浅色运动穿搭调性”“厨房台面使用氛围”。
- 对未被选中的元素写清排除或改写，例如参考图中的原鞋/产品、品牌、logo、具体人物长相、具体衣服款式、具体墙面/街景/家具不直接复制。
- 不要写“参考图4风格”“参考浅色棒球服风格”这类宽泛指令；要改成“参考图用于借鉴明亮白底动态感、脚部清晰度和轻运动姿态；产品必须来自产品锚点图；参考图中的原鞋、人物长相、具体服装款式和背景不直接带入”。
- 场景图、上脚图、上身图、动态 pose 图也必须绑定产品锚点图；产品主体永远来自产品图/白底图/商品实拍图。
- 如果某张图只有参考图没有产品锚点图，生图状态标为不可执行，先补产品锚点图或改成不生成该图。

## 2.2 生图设置告知与比例引导

在 `主图策划.md` 的前部展示默认生图设置：

- 默认比例：1:1。
- 默认模型：Nona banana pro。
- 默认分辨率：1K。
- 可选：GPT image 2、3:4、2K。
- 模型、比例、分辨率可以混合选择；用户只改其中一项时，其余按默认。
- 默认文案模式：内嵌中文文字。

同时引导用户可以改生图设置：

| 设置项 | 默认 | 可选 |
|---|---|---|
| 比例 | 1:1 | 3:4 / 用户指定 |
| 模型 | Nona banana pro | GPT image 2 / 用户指定 |
| 分辨率 | 1K | 2K / 用户指定 |

如果用户没有选择，继续按 1:1、Nona banana pro、1K 执行，不要反复追问。

## 3. 五张主图节奏和转化逻辑

主图节奏是用户从刷到商品到愿意点击/下单的心理推进顺序。默认按这条线规划：

```text
第一眼点击 -> 建立兴趣/代入 -> 证明价值 -> 消除顾虑 -> 推动决策
```

默认5张图按这个节奏递进：

| 图序 | 节奏任务 | 重点 | 画面感觉 |
|---|---|---|
| 主图1 | 抢点击 | 商品第一眼、风格、核心利益点 | 最干净、最有识别度、不要信息太满 |
| 主图2 | 建代入 | 使用场景、人群状态、穿搭/使用效果 | 有场景感，让用户想象“我用它” |
| 主图3 | 讲核心卖点 | 材质、功能、差异化优势 | 更聚焦产品，信息比主图1略多 |
| 主图4 | 解顾虑 | 细节、对比、痛点回应、品质证明 | 更理性，适合局部放大/结构说明 |
| 主图5 | 做收口 | 卖点总结、SKU/颜色/规格、购买理由 | 信息最完整，但仍要清楚不乱 |

可以根据品类调整顺序，但每张图必须有不同节奏任务。调整时只改“重心”，不要打乱完整决策链：

| 品类/情况 | 常见调整 |
|---|---|
| 鞋服箱包/饰品 | 主图2优先上身/上脚/穿搭代入，主图3再讲材质和版型 |
| 小家电/3C/工具 | 主图2可提前做产品确认/使用场景，主图3-4讲功能和适配顾虑 |
| 护肤/食品/母婴 | 主图2建立使用场景或肤感/口感想象，主图3-4严格控制功效、成分、认证等事实边界 |
| 高客单/强信任商品 | 主图2可偏品质信任，主图4强化评价顾虑和细节证明 |
| SKU/规格复杂商品 | 主图5必须承担选购收口，避免前4张塞满规格信息 |

五图不要平均分配卖点。先判断这个商品最需要哪种转化任务：

| 任务 | 适用情况 | 常见位置 |
|---|---|---|
| 点击 | 商品需要在搜索/推荐流里先被点开 | 主图1 |
| 信任 | 质量、材质、服务、安装、正品、耐用是主要顾虑 | 主图2/3 |
| 差异化 | 同质化严重，需要和竞品拉开 | 主图2/3 |
| 顾虑消除 | 评价/问大家集中在尺寸、适配、使用、售后 | 主图3/4 |
| 场景代入 | 用户需要看到使用结果、搭配效果、送礼/家居/穿搭氛围 | 主图4/5 |
| 规格/SKU | 购买前必须确认规格、容量、套装、型号 | 主图5 |

输出时只保留一个“主图执行总览”表，合并转化任务、痛点/机会、主卖点、画面设计逻辑、文案方向和风险；不要同时输出“主图作战表”和“主图设计逻辑总览”两张高度重复的表。

## 4. 提示词原则

- 默认中文提示词。
- 画面内文案默认中文。
- 单图完整提示词必须能直接复制到当前宿主。
- 单图提示词必须写清本图使用的产品锚点图和参考资产；参考资产要写“本次借鉴什么”和“不借鉴/需改写什么”。
- 不要在单图 prompt 前重复长段设计逻辑；设计逻辑集中放在文件开头总览表。
- 产品保持优先于风格。
- 参考图不能替代产品结构；人物、服装、产品、道具和背景是否借鉴，按本图策划逐项判断，写清可借鉴与需改写边界。
- 每张单图 prompt 必须复制完整的 `【系列统一】` 内容。不能写“继承系列统一规范”“同上”“参考上文”，因为生图执行时单图 prompt 往往会被单独发送。

## 5. 生图前确认

提示词文件保存后必须停下来问用户：

```text
你要先按修改意见调整，还是确认继续用当前宿主生成这5张主图？
```

用户明确回复“确认生图/继续生图/用当前宿主生成/直接生成”后，直接进入 `当前宿主工具` 执行，不再二次确认。

## 6. 宿主资产执行规则

- 产品图、白底图或商品实拍图是产品事实锚点；参考图和竞品图只承担明确写出的视觉参考角色。
- 宿主支持图像工具时，按图序交付完整提示词、资产角色、比例、模型和分辨率；宿主不支持时交付相同内容的执行清单。
- 每张图生成后记录输出位置、提示词版本和质检结论，不虚构生成状态。

## 7. 生成后迭代

当前宿主生成后，如果能查看结果图，做一次复盘再结束：

- 标出需要重试的图序。
- 说明重试原因：产品跑偏、文字错误、视觉重复、主卖点不清、构图不适合小图等。
- 给出下一版调整 prompt 的方向，不要只说“重新生成”。
