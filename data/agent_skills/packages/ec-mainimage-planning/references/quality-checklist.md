# 质量检查与二次修图

## 单图验收

每张图生成后检查：

- 产品是否变形
- 产品颜色是否与原图一致
- 产品结构是否被改变
- 是否新增了不存在的配件/接口/logo/图案
- 主体小图是否清楚
- 目标人群标签是否明显
- 视觉目标是否匹配成交心智
- 文字是否可读、准确
- 是否有虚假卖点或错误参数
- 是否符合本图销售任务

## 套图统一检查

- 5张图色调是否统一
- 是否先建立了明确的视觉规范系统，而不是边写边变
- 是否每张 prompt 都继承同一个系列统一块
- 色彩分组是否清楚，例如 A组负责生活/点击，B组负责产品/细节，C组负责SKU/收口
- 字体是否同一体系
- 标签/图标是否同一风格
- 产品颜色是否一致
- 光影是否连贯
- 是否像同一个品牌的一套图
- 是否每张任务不同但气质一致
- 主标题标点是否一致，默认不加句号
- 标签长度和表达方式是否一致
- 画面内是否避免出现色值、字体名称、提示词说明等不该出现的文字

## 输入-输出顺承检查

对照输入图和结果图检查：

- 产品图是否只负责锁事实，输出是否保持了产品结构、颜色、比例和材质视觉。
- 参考图是否真的被继承：构图、光线、人物裁切、留白、文字密度、情绪是否相近。
- 包装图是否使用过度；包装是否连续多张强中心，导致套图节奏单调。
- 场景辅助物是否被误画成赠品或商品组成部分。
- 用户文字卖点是否被当成事实硬背书；认证、检测、参数、产地、无添加等是否有证据。
- 审美驱动品是否被过度做成参数/详情页模板。
- 食品/标品是否只重复包装，缺少口感、使用场景或信任证据的视觉证明。

## contact sheet 检查

当前宿主生成5张图后，环境允许时生成一张总览拼图/contact sheet，用来快速检查：

- 5张是否像同一品牌的一套图。
- 产品颜色和形态是否前后一致。
- 信息密度是否忽高忽低。
- 主图1是否有搜索点击力，主图2-5是否任务分明。
- 是否某一张明显跑偏，需要单独重出。

如果无法生成拼图，在结果文件里输出同样维度的套图对照表。

## 二次修图/重生成指令

| 问题 | 处理 |
|---|---|
| 产品变形 | 降低重绘幅度，强化产品保持，减少对产品结构描述 |
| 背景抢主体 | 简化背景，提高主体占比 |
| 文字错误 | 优先重出带文字版并缩短文案、强化字体和层级；多次失败再追加后期排版备选 |
| 文字系统不统一 | 保留带文字主方案，强化字体、字号、字重、标点、标题层级和标签长度；不要直接改成无字 |
| 不够卖货 | 加强标签、利益点、构图冲击或信任证据 |
| 太廉价 | 减少促销元素，增加留白、材质、光影秩序 |
| 太高级不转化 | 增加功能信息、规格、利益点或使用场景 |
| 风格不统一 | 回到全局视觉母版，统一色调、字体、标签 |
| 参考图继承弱 | 提高视觉继承强度，减少参数卡和详情页模板，重写构图/光线/文字密度约束 |
| 包装出现过多 | 调整包装使用节奏，指定哪些图不出现包装或只作角落辅助 |
| 辅助物像赠品 | 明确辅助物只作场景，不表现为商品附带 |
| 材质错误 | 删除不确定材质词，改为“保持如图材质视觉特征” |
