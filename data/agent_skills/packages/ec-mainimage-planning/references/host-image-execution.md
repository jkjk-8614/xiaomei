# 图像工具执行说明（通用）

## 边界

本说明只规定资产角色、提示词传递和结果验收，不调用特定 CLI、宿主工作区、宿主工具协议、API 或私有服务。实际生成由当前宿主提供的图像工具完成。

## 执行流程

1. 确认产品锚点图、参考图、竞品图、包装图和详情页截图的角色；产品锚点图负责保持产品事实，参考图只承担明确写出的构图、光线、色彩或场景参考。
2. 读取策划文件中的比例、模型、分辨率和统一视觉规范。模型可在当前宿主支持时选择 GPT Image、Banana/Nano Banana 等选项；未支持时保留为文字参数，不自行假设已经执行。
3. 将完整提示词连同产品锚点图和必要参考图交给当前宿主。需要批量生成时按图序逐张提交，并记录图序、资产映射、提示词版本和输出位置。
4. 生成后检查产品外观、文字可读性、构图、比例、色彩、参考图边界和套图一致性；不合格时只修改对应提示词并记录重试原因。

## 宿主没有图像工具时

输出可直接复制的完整提示词、负面提示词、图片角色表、模型/比例/分辨率建议、逐图执行清单和验收清单。不得把“已提交”“已生成”“已保存”写成事实。

## 交付记录

建议记录：输入资产路径或附件标识、资产角色、每张图的完整提示词、使用的宿主工具和模型（如有）、输出文件路径、质检结论和待修改项。
