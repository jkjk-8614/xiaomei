# 统一视觉规范系统

本文件用于把“好看的单张图”升级为“统一的一套主图”。先建立视觉规范系统，再写5张主图提示词。

## 什么时候读取

遇到以下情况必须读取：

- 用户要求整体视觉统一、品牌视觉规范、统一色调、统一字体、统一主图风格。
- 用户提供品牌规范、参考提示词、成套主图模板、竞品5张主图或自家现有5张主图。
- 输出的5张图需要直接交给当前宿主生成，且需要像同一品牌的一套图。

## 从参考文件提炼规范

如果用户提供参考提示词或品牌规范，先提炼“可复用规范”，不要直接照抄品类细节。

| 提炼层 | 要提炼什么 | 不要照搬什么 |
|---|---|---|
| 品牌/品类DNA | 核心定位、功能关键词、情绪关键词、场景关键词、价值关键词 | 参考文件里的固定品牌名、固定品类、不可证实卖点 |
| 色彩系统 | 主色、辅助色、背景色、文字色、强调色、分组规则 | 和当前商品颜色冲突的色值 |
| 字体系统 | 中文字体、英文字体、字重、标题/标签层级、标点习惯 | 参考文件里不适合当前平台的小字号或复杂字体 |
| 图标/标签 | 线条粗细、标签形状、标签长度、图标风格 | 未证实功能图标和认证标 |
| 图片规范 | 比例、清晰度、质感、光线、背景、产品占比、留白 | 不适合当前商品的场景和人物设定 |
| 套图结构 | 5张图的任务分配和色彩分组 | 竞品文案、竞品商品事实、竞品品牌资产 |
| 检查清单 | 产品保持、色调统一、字体统一、光线统一、任务不同 | 只适合单一案例的硬编码描述 |

## 必须输出视觉规范系统

在 `主图策划.md` 中，5张提示词之前必须先输出：

1. 品牌/品类DNA
2. 色彩分组
3. 字体/标签/图标系统
4. 构图和光线规则
5. 系列统一 prompt 继承块

## 视觉控制维度

视觉规范不要写成死模板，而要写成一组“控制维度”。每个维度都判断控制强度：

- **锁定**：5张图必须一致，不能变。
- **弹性**：允许随图序任务变化，但要在同一视觉家族内。
- **自由**：不强控，只要不破坏商品事实和套图统一即可。
- **禁止**：明确不能出现的偏离。

| 维度 | 控制目标 | 常见控制强度 | 说明 |
|---|---|---|---|
| 品牌/品类气质 | 让5张图像同一个品牌/价格带 | 锁定 | 例如高级、亲近、科技、复古、自然、强促销，不要每张换气质 |
| 色彩家族 | 控制主色、辅助色、背景色关系 | 锁定/弹性 | 可以分 A/B/C 组，但不要无规则乱跳 |
| 光线语言 | 控制自然光、棚拍光、侧光、逆光、冷暖 | 锁定/弹性 | 场景图和产品图可不同，但冷暖和质感要连贯 |
| 背景质感 | 控制纯色、渐变、生活场景、材质背景 | 弹性 | 随图序变化，但要共享同一质感逻辑 |
| 构图节奏 | 控制居中、黄金分割、低角度、俯视、微距 | 弹性 | 单图可变化，套图要有节奏 |
| 产品占比 | 控制主体大小和识别度 | 锁定/弹性 | 主图通常保持稳定区间，细节图可放大 |
| 字体层级 | 控制标题、标签、说明、数字的层级 | 锁定 | 字体体系、字重、标点、层级必须统一 |
| 标签/图标系统 | 控制标签形状、线条、颜色、图标风格 | 锁定 | 尤其适合功能点、卖点总结、详情页标注 |
| 信息密度 | 控制文字多少、标签数量、留白 | 弹性 | 主图1可以更克制，卖点图可略密，但不能忽高忽低 |
| 场景和道具 | 控制生活场景、道具、人物、空间 | 弹性/自由 | 只要符合人群和价格带，不误导为赠品 |
| 人物/模特风格 | 控制年龄、穿搭、姿态、裁切 | 弹性 | 有人物时要同一人群气质，不必同一人物 |
| 材质和细节表现 | 控制纹理、反光、锐度、真实感 | 锁定 | 产品材质视觉必须前后一致 |
| 后期质感 | 控制胶片感、锐化、颗粒、对比度 | 锁定/弹性 | 可以轻微变化，但不能一张写实一张塑料感 |
| 平台适配 | 控制比例、小图可读、文字安全区 | 锁定 | 淘宝/天猫默认 1:1，小图识别优先 |

## 维度选择规则

不要把上面的维度全部机械写进每个项目。先根据商品资料、参考图、平台和用户目标，选出最能影响这套图统一感的 5-8 个维度。

默认选择：

- **必选 3 个底盘维度**：品牌/品类气质、产品事实和材质表现、平台适配。
- **再选 2-3 个视觉维度**：色彩家族、光线语言、背景质感、构图节奏、产品占比。
- **按需选择表达维度**：字体层级、标签/图标系统、信息密度、场景和道具、人物/模特风格、后期质感。

选择时遵循：

| 情况 | 优先启用的维度 | 控制方式 |
|---|---|---|
| 用户给了品牌规范/参考提示词 | 色彩家族、字体层级、标签系统、光线语言 | 提炼可复用规则，不照搬固定品类和品牌名 |
| 用户给了竞品5张图 | 套图结构、构图节奏、信息密度、卖点顺序 | 借鉴结构，不照搬竞品事实和视觉资产 |
| 用户给了自家5张旧图 | 产品占比、信息密度、文案层级、风格断裂点 | 保留有效识别，修正不统一和低转化点 |
| 产品颜色/材质很强 | 产品颜色、材质细节、背景匹配、光线冷暖 | 围绕产品智能匹配，不强行套固定色值 |
| 资料少但要快速出方案 | 品牌/品类气质、平台适配、产品保持、色彩家族、文字安全区 | 建轻量规范，把强事实标为待确认 |

输出时要让用户看得懂“这套图主要靠哪些维度统一”。不要堆概念；每个启用维度都要能落到后续 5 张 prompt。

## 锁定/弹性/自由表

在策划时，把视觉规范写成这样的判断，而不是只写“高级、统一”：

| 控制强度 | 本次项目对应维度 | 规则 |
|---|---|---|
| 锁定 |  | 5张图必须一致 |
| 弹性 |  | 允许随图序变化，但共享同一视觉家族 |
| 自由 |  | 可根据单图销售任务发挥 |
| 禁止 |  | 不允许出现 |

示例：

| 控制强度 | 本次项目对应维度 | 规则 |
|---|---|---|
| 锁定 | 产品颜色、字体体系、文字安全区、品牌气质 | 所有图保持一致 |
| 弹性 | 背景深浅、场景类型、构图角度、信息密度 | 按主图任务变化，但不跳出同一色彩家族 |
| 自由 | 道具、局部视角、人物姿态 | 只要不误导商品事实即可 |
| 禁止 | 冷白光、乱码文字、虚假认证、竞品品牌元素 | 任一图都不能出现 |

## 色彩分组规则

色彩分组不是固定色值，而是让一套图有节奏：

| 分组 | 常见用途 | 规则 |
|---|---|---|
| A组 | 主图1-2，点击/生活场景/人群代入 | 色调较亲近，光线自然，场景感更强 |
| B组 | 主图3-5，产品质感/细节/卖点总结 | 色调更稳、更聚焦产品，背景更克制 |
| C组/智能匹配 | 规格、SKU、多色、纯产品展示 | 根据产品颜色或平台需求调整，不破坏前两组风格 |

如果用户提供明确色值，可以沿用；如果没有色值，用文字描述可执行色彩，例如“低饱和暖米色”“深焦糖棕”“冷灰棚拍背景”。

## 系列统一 prompt 继承块

系列统一块不是固定的一句话，而是根据当前产品和视觉规范系统生成的“本项目专属视觉母版”。每个项目只生成一版，然后 5 张主图都复制同一版，保证整套画面像同一品牌、同一系列。

每张主图提示词都必须包含同一个系列统一块。系列统一块只放“锁定”和必要“弹性边界”，不要把所有自由发挥内容都塞进去。它负责锁住：

- 品牌/品类DNA
- 色彩分组
- 字体和标签系统
- 产品颜色、材质视觉、结构比例
- 光线方向和背景质感
- 留白、安全区、文字层级
- 不出现色值、字体名称、错误文字、虚假认证

示例：

```text
【系列统一】
这5张图属于同一套[平台/品类]主图，整体气质统一为[本商品专属品牌/品类气质]；产品必须保持[本商品颜色、材质、结构、关键识别点]一致；画面使用[本项目色彩家族和分组规则]，文字使用[本项目中文字体/标签/图标风格]，光线保持[本项目光线语言]，背景保持[本项目背景质感边界]，保留[本项目留白和文字安全区规则]。允许[本项目可弹性变化项]随主图任务变化，但不得出现[本项目禁止项]。
```

输出时必须把方括号内容替换成当前项目的具体内容，不能原样保留占位符。

每张单图再用“本图视觉分组 / 色调 / 光线 / 字体继承”补充变化项，例如本图场景、视角、道具、信息密度和主卖点。不要用“同上”代替系列统一块。

## 单图允许变化

统一不等于每张都一样。允许变化：

- 转化任务不同
- 场景不同
- 构图视角不同
- 主卖点不同
- 产品局部/整体展示不同
- 信息密度有轻微节奏变化

不允许变化：

- 像不同品牌
- 产品颜色忽深忽浅
- 字体、标签、标点各用一套
- 光线从暖调突然变冷白
- 背景质感断裂
- 主图1-5重复同一个卖点

## 灵活性原则

视觉规范的目的不是限制创意，而是限制“失控”。默认遵循：

- 锁定少数会造成断裂的维度：品牌气质、产品事实、字体体系、色彩家族、光线冷暖、文字安全区。
- 放开能服务销售任务的维度：场景、视角、道具、局部/整体、人物动作、卖点表达。
- 不把参考案例的固定色值、人物、品牌名、品类道具硬套到新商品。
- 如果用户提供明确品牌规范，优先尊重用户规范；如果没有规范，自动建立一套轻量规范。
- 如果产品本身颜色很强，视觉系统要围绕产品主色智能匹配，而不是强行套某个色调。

## 提示词自检

输出最终提示词前，检查并优化：

- 5张是否都包含产品保持要求。
- 5张是否都继承同一个系列统一块。
- 色彩分组是否清楚。
- 字体、标签、图标、标点是否统一。
- 主图1-5是否任务不同但气质一致。
- 画面内是否避免出现色值、字体名称等不该出现的文字。
- 是否覆盖错误文字、产品变形、虚假卖点等负面项。
