# 主图策划

电商五张主图策划 skill。可读取主图分析、商品资料、产品图、竞品图、参考图或表格证据，输出转化任务、视觉规范、逐图方案和中文生图提示词。

## 使用模式

- 有分析文件：读取结构化交接并按证据边界策划。
- 有产品资料：先做轻量事实检查，再输出五图方案。
- 有现有套图：拆解图序和视觉规则，再做改版或转译。
- 资料不足：照常输出低置信度方案，并列出待确认项。

## 执行边界

本 skill 不绑定特定软件、CLI、宿主工作区、宿主工具协议 或保存目录。宿主提供图像工具时，交付完整提示词和产品锚点图后由宿主执行；宿主不提供时，输出可复制的提示词、资产表、参数建议和质检清单，不声称已经生成图片。

## 默认输出

在当前工作目录下保存 `./outputs/mainimage/`，也可遵从用户指定的工作路径。
