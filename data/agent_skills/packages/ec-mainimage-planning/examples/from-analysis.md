# 示例

用户：

> 根据这个主图分析.md 做主图策划和生图提示词。

输出：

- 读取 `主图分析.md` 末尾的结构化交接。
- 检查产品图/白底图/商品实拍图是否存在。
- 保存 `主图策划.md`。
- 对话框只返回文件路径，并询问是否修改或继续生图。

## 示例 2：单独使用 planner

用户：

> 我没有主图分析，直接根据这些产品图和卖点出5张淘宝主图提示词。

输出：

- 不要求先运行 analyzer。
- 先做输入资产检查和轻量分析。
- 保存 `主图策划.md`，每张提示词标明使用哪些产品图/参考图。

## 示例 3：缺产品图但先策划

用户：

> 先帮我把五张主图方案写出来，产品图晚点补。

输出：

- 可以保存 `主图策划.md`。
- 生图状态标为“暂不可执行：缺产品事实锚点图”。
- 提醒用户上传产品图/白底图/商品实拍图后再调用当前宿主。

## 示例 4：确认生图

用户：

> 确认，用当前宿主生成。

输出：

- 读取 `references/当前宿主工具-execution.md`。
- 做当前宿主执行前置检查。
- 前置检查通过后直接执行，不再二次确认。
