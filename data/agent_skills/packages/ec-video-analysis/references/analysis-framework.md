# Ec-video-analysis 框架

生成详细 ec-video-analysis 报告时使用本框架。

## 最少需要收集的证据

- 元数据：时长、画幅比例、分辨率、帧率、是否有音频、文件/封装信息等。
- 视频帧：固定时间线采样帧，以及场景切换帧或关键时刻帧。
- 视觉识别：带时间戳的画面文字、字幕、贴片、行动号召、品牌/产品提及、价格、免责声明、界面标签，以及产品外观、人物动作、场景、构图、色彩、表情等非文字视觉证据。
- 音频/语音：如果可访问，记录语音密度、音乐情绪、静音、音效、音量动态、说话语气。
- 剪辑标记：切镜、转场、推拉变焦、镜头运动、变速、叠加图层、动效等。

## 分析维度

### 1. 结构与时间线

将视频拆成多个时间段。每个片段说明：

- 主要视觉内容。
- 画面文字或字幕内容。
- 可识别的说话内容或音频事件。
- 叙事功能，例如开场钩子、铺垫、演示、证明、异议处理、优惠、行动号召、过渡、总结、结尾等。
- 片段有效性，以及可能存在的理解阻力。

### 2. 视觉识别与文案

评估：

- 前 1-3 秒钩子是否清晰。
- 关键卖点、利益点、产品名、价格、行动号召是否出现，并且停留时间是否足够阅读。
- 文案层级：主标题、辅助文案、标签、字幕、免责声明。
- 是否存在重复、冗余、信息缺失或前后冲突。
- 移动端可读性：字号、对比度、位置、安全区、遮挡、出现时长。
- 说服机制：具体性、证明、紧迫感、社会认同、新奇感、好奇心、风险逆转。
- 非文字视觉信息是否支撑文案，例如动作演示是否证明“抓地”“轻便”“防水”“舒适”等主张。

### 3. 节奏与韵律

评估：

- 平均镜头时长和体感剪辑速度。
- 开头、中段、结尾的节奏变化。
- 运动密度、镜头运动、转场频率、叠加元素频率。
- 信息密度：观众是否有足够时间理解画面和文案。
- 音频节奏：语速、卡点、静音、强调点；仅在音频可用时分析。
- 可能导致流失的节点：开头慢、中段重复、转场不清、文字过载、行动号召弱等。

使用具体表述，例如“开场快、中段证明放慢、结尾行动号召压缩”，避免只说“节奏好/不好”。

### 4. 情绪与调性

评估：

- 主导情绪曲线：好奇、紧张、信任、向往、紧迫、释然、愉悦、权威、共情、恐惧、幽默、平静等。
- 视觉情绪：色温、对比度、光线、构图、表情、环境。
- 音频情绪：音乐类型、速度、人声能量、音效、静音；仅在音频可用时分析。
- 文案情绪：承诺、痛点、身份感、问题-解决、可信度、稀缺感。
- 情绪与目标的匹配度。例如教育内容更需要清晰和信任，广告素材通常更需要开场强度和转化推进。

情绪分析必须标注为基于可观察线索的推断。

### 5. 视觉表达

评估：

- 构图、取景、焦点、产品可见度、主体突出程度。
- 品牌一致性：Logo、颜色、字体、语气、制作质感。
- 场景清晰度与连续性。
- 是否有效使用演示、前后对比、录屏、证言、证明、生活场景。
- 视觉层级是否能引导观众看向正确焦点。

### 6. 剪辑与制作

评估：

- 切镜逻辑、转场、蒙太奇流动、B-roll 相关性、变速处理。
- 动效、字幕、贴片、贴纸、特效是否服务内容，还是造成干扰。
- 是否存在跳切突兀、空白停顿、镜头重复、顺序混乱等问题。
- 平台适配：横竖屏、画面安全区、字幕位置、封面潜力。

### 7. 受众与平台适配

基于证据推断：

- 目标观众的问题、欲望、认知程度和注意力长度。
- 平台场景：TikTok/Reels/Shorts、YouTube 长视频、电商详情页、直播课、课程、付费广告、内部培训等。
- 开头、节奏、字号、行动号召是否符合可能的平台习惯。
- 是否存在限制传播的文化、语言或语境假设。

### 8. 转化或沟通效果

适用时分析：

- 优惠/主张是否清晰，行动号召出现时间、文案和下一步门槛是否合理。
- 信任构建：证明、资质、证言、数据、演示、保障。
- 异议处理：价格、难度、质量、可信度、时间、安全性、兼容性。
- 缺失素材：产品特写、使用场景、结果证明、对比、用户证言、行动号召页。

### 9. 风险与合规

在不提供法律结论的前提下提示潜在问题：

- 可能误导或缺乏依据的宣称。
- 难以阅读的免责声明。
- 敏感内容、健康/金融宣称、未成年人、隐私、版权素材、平台政策风险。
- 无障碍问题，例如缺字幕、低对比度、闪烁、关键信息只存在于音频中。

## 分析文件输出要求

每次完整 ec-video-analysis 都必须生成一个分析文件。默认使用 Markdown，除非用户指定其他格式。

文件建议：

- 将文件保存到用户当前工作目录、视频同级目录，或明确命名的分析输出目录。
- 文件名应包含原视频名或可识别任务名，例如 `<视频文件名>-analysis.md`。
- 如果同时生成抽帧、联系表或音频统计等辅助产物，在分析文件中记录这些产物路径。
- 最终聊天回复必须包含“报告总结”，概括核心结论、主要发现、关键问题和优先建议；同时明确说明详细分析报告已生成到文件，并提供分析文件路径。

## Ec-video-analysis 报告总结要求

聊天里不要粘贴完整详细报告；应提供一个清晰的报告总结。建议包含：

- 一句话说明视频类型、主题和可能目标。
- 3-5 条最重要发现。
- 2-4 条优先优化建议。
- 明确写出：`详细分析报告已生成到文件：<路径>`。

## 分析文件模板

除非用户要求其他格式，否则使用以下结构：

```markdown
**视频基础信息**
- 来源：
- 时长：
- 分辨率/画幅比例：
- 采样方法：
- 视觉识别方法：
- 音频/语音处理方法：

**执行摘要**
简要说明视频核心信息、可能目标、最强优势和最大优化机会。

**时间线拆解**
| 时间 | 画面 | 视觉识别/文案 | 音频/语音 | 功能 | 备注 |
|---|---|---|---|---|---|

**视觉识别结果**
- 关键画面文案：
- 重复字幕/贴片：
- 行动号召/优惠/价格：
- 关键非文字视觉信息：
- 可读性问题：
- 低置信度文本：

**节奏与韵律**
分析开头速度、剪辑节奏、信息密度、转场、拖慢/过载节点，以及对留存的可能影响。

**情绪与调性**
描述情绪曲线，并引用可观察线索。区分证据和推断。

**视觉与剪辑分析**
分析构图、产品/主体清晰度、视觉层级、转场、制作质感和平台适配。

**叙事 / 信息架构**
说明钩子、铺垫、证明、价值传递、异议处理、行动号召的流程。

**受众与意图**
推断目标受众、适配平台，以及传播/转化目标。

**优势**
列出有证据支持的优势。

**问题 / 风险**
列出有证据支持的问题、模糊点、合规或无障碍风险。

**优化建议**
给出具体建议，并尽量按影响优先级排序。

**证据记录**
列出带时间戳的观察、帧编号、视觉识别文案片段、关键画面线索和置信度说明。
```

## 评分 Rubric

如果评分有帮助，使用 1-5 分，并为每项给出简短理由：

- 开场钩子强度。
- 信息清晰度。
- 视觉识别/文案可读性。
- 节奏与留存潜力。
- 情绪匹配度。
- 视觉层级。
- 剪辑完成度。
- 平台适配度。
- 转化或沟通效果。
- 无障碍友好度。

不要给没有证据支撑的分数。
