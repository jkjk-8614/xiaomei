确认商品到底是连衣裙还是两件套，统一信息

## 技能简介

对必填的视频文件或视频 URL 进行分析：提取代表性视频帧，通过视觉识别路径读取画面文案和关键视觉信息，分析节奏、情绪、叙事结构、剪辑方式、视觉表现、可用音频线索，并生成一个详细的 ec-video-analysis 多维度分析文件。当用户要求分析、诊断、总结、拆解、复盘、对标或评估视频、短视频、广告素材、产品视频、社媒视频、课程视频、直播录屏等视频内容时使用
