# 1688供应商查询指南

## ⚠️ 核心限制

**失败时直接告知用户，不编造！**

```
❌ 禁止：编造供应商信息、伪造工厂数据、臆测供应商资质...
✅ 仅允许：如实返回CLI工具结果，失败时告知用户原因
```

## 会话授权状态

**授权检查规则**：
- 同一会话内，首次查询时检查 AK 授权状态
- 若已授权：直接执行查询，无需重复验证
- 若未授权：**自动执行 `python3 cli.py get_ak`，不要询问用户**

## AK 授权处理

### 未授权时处理流程

当 CLI 返回 `needAuth: true` 或提示 AK 未配置时：

**必须自动执行以下流程，不要询问用户选择哪种方式：**

```
1. 停止后续所有操作
2. 自动执行：python3 cli.py get_ak（通过浏览器获取 AK）
3. 等待浏览器授权完成
4. get_ak 返回 success=true → AK 已自动写入，记录会话已授权状态，继续原查询
5. get_ak 返回 success=false → 告知用户获取失败，请手动提供 AK 字符串
```

**关键：不要询问用户"请提供 AK"或"选择哪种方式"，直接执行 `python3 cli.py get_ak`。**

## 服务失败处理

### 重试机制

当服务返回失败时，CLI会自动进行最多3轮重试：

```
第1次失败 → 等待1秒 → 第2次重试
第2次失败 → 等待1秒 → 第3次重试
第3次失败 → 停止重试，告知用户
```

### 3轮重试后依然失败时

```
1. 立即停止后续一切操作
2. 直接告知用户失败原因和重试次数
3. 不要尝试其他方式获取数据
4. 不要使用搜索引擎补充
5. 不要编造信息填补
6. 等待用户处理后重试
```

**Agent 禁止行为**：
- ❌ 不要手动重试（CLI已自动重试3次）
- ❌ 不要使用搜索引擎补充
- ❌ 不要使用其他工具获取数据
- ❌ 不要编造信息填补空缺
- ❌ 不要访问外部网站
- ✅ 直接告知用户失败原因，等待用户指示

## AK 配置读取

AK 存储在本地 `{workspace}/.1688-AK/.ak_store.json` 文件中（与 1688-auth-skill-for-wukong 共享同一存储路径），通过命令管理：

```bash
# 通过浏览器获取 AK（AK 未配置时自动执行）
python3 cli.py get_ak

# 手动设置 AK
python3 cli.py configure YOUR_AK

# 查看 AK 状态
python3 cli.py configure --status
```

### 浏览器获取 AK（get_ak）

**授权页面**：`https://air.1688.com/app/tai/oauth_page/index.html`

**流程**：执行 `python3 cli.py get_ak` → 脚本自动启动本地回调服务器（端口 8080）→ 构造授权 URL（含 `mode=AK&state=xxx&redirect_uri=http://localhost:<port>/callback`）→ 打开浏览器到 1688 授权页 → 用户登录确认 → 1688 回调返回 AK → 自动写入 ak_store → 输出 `{"success": true, "data": {"ak": "<AK>"}}`

**关键**：`redirect_uri` 中的 `localhost` 和端口由脚本动态分配，平台只需执行 `python3 cli.py get_ak`，脚本全自动完成，无需手动构造 URL。AK 存储路径与 1688-auth-skill-for-wukong 完全一致，两个 skill 共享同一 AK。

## Agent 处理流程

```
步骤1: 检查会话授权状态
       ├─ 已授权 → 继续
       └─ 未授权 → 自动执行 python3 cli.py get_ak → 授权成功 → 记录状态 → 继续

步骤2: 提取关键字 → 商品词 + 供应商词

步骤3: 调用CLI → python3 cli.py ali_1688_source_suppliers -q "<关键字>"

步骤4: 处理响应
       ├─ success: true → 输出表格 + Agent分析
       └─ success: false → 返回失败原因 + 引导链接 → 终止

注意：引导链接仅在查询失败时显示，供用户手动搜索。
```

## 异常处理

| 场景 | 响应字段 | Agent 动作 |
|------|---------|-----------|
| AK未授权 | `needAuth: true` | **自动执行 `python3 cli.py get_ak`**，不要询问用户 |
| 服务失败（已重试3次） | `success: false`, `retries: 3` | 直接告知用户失败原因，不要使用其他方式补充 |
| 参数缺失 | `success: false` | 直接告知用户缺少参数 |
| 限流/429 | `success: false` | 直接告知用户请稍后重试 |

**重试机制**：CLI自动重试3次，Agent无需手动重试。

**核心原则**：失败时直接告知用户，不要尝试其他方式获取或补充数据。
