# A1-市场洞察·词路买家定位分析

根据输入的生意参谋搜索关键词数据，**模型临时归纳赛道**后，生成标准化的词路买家定位分析 Excel。

## 一、技能信息

| 项目 | 内容 |
|:---|:---|
| **技能编号** | A1 |
| **技能名称** | 词路买家定位分析 |
| **所属阶段** | A1-市场洞察 |
| **核心数据源** | 搜索关键词(生意参谋) |
| **输出格式** | Excel |

## 二、工作模式

```
模型读取数据 ──→ 临时归纳赛道规则 ──→ 传给脚本 ──→ 生成 Excel
                      ↑
              赛道定义（焦虑/定位/产品/定价/竞争）
```

**关键：脚本零内置规则。** 赛道划分完全由模型在运行时根据数据临时归纳，通过参数传入脚本。脚本只负责格式化输出。

## 三、调用流程

### 步骤1：模型分析数据，归纳赛道

读取输入文件，分析关键词分布，按语义临时归纳赛道。规则格式：

```json
{
  "夏季薄款": ["夏薄款", "夏季", "男夏", "夏薄", "夏天"],
  "天丝莱赛尔面料": ["天丝", "莱赛尔", "冰丝"],
  "大码加长尺码": ["大码", "加长", "高个子"]
}
```

规则逻辑：关键词包含列表中**任一**子串即命中该赛道。未命中任何规则的归为「品类通用」。

### 步骤2：模型补充赛道定义

为每个归纳出的赛道补充业务策略：

```json
{
  "夏季薄款": {
    "焦虑": "夏天穿太热/不透气",
    "定位": "超薄透气·凉感面料",
    "产品": "超薄亚麻+凉感工艺",
    "定价": "129~229",
    "竞争": "中等竞争"
  }
}
```

### 步骤3：调用脚本生成Excel

```python
from build_A1 import load_data, get_track_stats, create_excel

df = load_data(input_path, track_rules=track_rules)
tracks_df = get_track_stats(df, max_tracks=8)  # 只取前8赛道，其余归"其他"
create_excel(df, tracks_df, category, output_path, track_defs, title_kws)
```

## 四、呈现逻辑

16 Sheet：
- 0-核心发现总结
- 1-市场全景总览
- 2-预估支付买家数分析
- 3-垂直赛道规划总览
- 4-差异化定位执行表
- 5-蓝海策略与行动路线
- 6-指标说明手册
- P0/P1/P2-赛道名：每个赛道一个Sheet（最多8个主赛道+1个其他）

## 五、数据源要求

### 必填列

| 列名 | 说明 |
|:---|:---|
| `相关搜索词` | 搜索关键词 |
| `预估搜索人气` | 搜索量 |
| `预估支付买家数` | 预估购买人数 |

**数据源不需要「赛道」列。** 赛道由模型运行时临时归纳。

## 七、赛道归纳原则

1. **先读数据再归纳**：必须先看关键词列表，按语义聚类
2. **通用维度优先**：季节、面料、人群、尺码、颜色、风格、版型、长度等
3. **最多8个主赛道**：其余归为「其他」
4. **不写死到脚本**：赛道规则只存在于本次调用的参数中

## 八、通用赛道划分六步法（跨品类）

> 核心原则：**从搜索词的语义结构出发，而非具体产品属性**。任何品类的关键词都由「品类词根 + 修饰成分」构成，赛道划分就是识别并聚类这些修饰成分。

### Step 1: 读取数据全貌
- 读取文件，确认列名（`相关搜索词`、`预估搜索人气`、`预估支付买家数`等）
- 列出全部关键词，观察语义分布规律

### Step 2: 识别品类词根
找出所有关键词共有的**核心产品名**及其变体。例如：
- 服装：「亚麻裤」「男亚麻裤」「亚麻裤男」→ 词根 = "亚麻裤"
- 3C：「蓝牙耳机」「无线耳机」「降噪耳机」→ 词根 = "耳机"
- 家居：「行李箱」「拉杆箱」「旅行箱」→ 词根 = "箱"

**词根本身及其纯变体归为「品类通用」**。

### Step 3: 提取修饰维度（从数据中动态观察）

除去词根后，观察剩余成分高频出现的**修饰类型**。通用修饰框架如下：

| 修饰类型 | 语义作用 | 典型示例（因品类而异） |
|:---|:---|:---|
| **场景** | 在什么场景用 | 夏季、旅行、运动、户外、办公、家用 |
| **需求/痛点** | 解决什么问题 | 抗皱、大容量、降噪、快充、防水、便携 |
| **人群** | 给谁用 | 男、女、儿童、学生、中老年、大码 |
| **规格** | 什么规格/尺寸 | 加长、大码、10000毫安、20寸、500ml |
| **品质/档次** | 什么档次 | 高端、原装、进口、纯亚麻、官方旗舰店 |
| **品牌** | 什么品牌 | 优衣库、苹果、小米、无印良品 |
| **功能/特性** | 什么功能 | 快充、无线、折叠、透气、自动、智能 |
| **风格/款式** | 什么风格 | 老钱风、简约、复古、可爱、商务 |

**关键**：不是先定8个固定维度再硬套，而是**先看数据里实际出现了哪些修饰词**，再归到上述框架中。

### Step 4: 构建赛道规则并统计验证

对每个识别出的修饰维度，提取具体关键词子串，构建规则：

```json
{
  "场景-夏季": ["夏", "夏季", "夏天", "薄款"],
  "面料升级": ["天丝", "莱赛尔", "冰丝"],
  "人群-大码": ["大码", "加肥", "加大"]
}
```

统计每个赛道的：
- 关键词数量
- 预估搜索人气总和
- 预估支付买家数总和

按**买家数**降序排列，初步筛选前8个赛道。

**排序原则**：把**更具体、更具差异化**的赛道放在前面，避免基础维度过早吞并具体需求。

### Step 5: 检查与修正

**5.1 检查"品类通用"占比**
- 若"品类通用"占比 **> 50%**，说明修饰规则覆盖面不足
- 修正方向：补充同义词、放宽匹配子串

**5.2 合并低频赛道**
- 若多个赛道买家数均 **< 50**（或占比过低），考虑合并为更宽维度
- 例：「儿童」+「青少年」+「中老年」→「人群细分」

**5.3 检查规则冲突**
- 一个关键词可能命中多个赛道（如"夏季薄款宽松"同时命中场景+版型）
- **处理原则**：按`track_rules`字典顺序，命中第一个匹配的赛道
- 建议：把更具体的赛道放前面

### Step 6: 补充业务定义并生成

为每个最终赛道补充策略五要素：
- **焦虑**：消费者核心痛点
- **定位**：差异化价值主张
- **产品**：具体产品方案
- **定价**：价格区间
- **竞争**：竞争程度评估

```python
df = load_data(input_path, track_rules=track_rules)
tracks_df = get_track_stats(df, max_tracks=8)
create_excel(df, tracks_df, category, output_path, track_defs, title_kws)
```

**验证 checklist**：
- [ ] 赛道总数 ≤ 9 个（8主 + 其他）
- [ ] "品类通用"占比 < 50%
- [ ] 各赛道买家占比分布相对合理
- [ ] 赛道命名反映真实修饰维度（不是硬凑的）

## 九、输出规范

- **文件名格式**：`[品类]_A1_词路买家定位分析.xlsx`
- **Sheet 命名**：按呈现逻辑
- **样式规范**：统一配色体系（深棕+金、深蓝+白、浅绿、浅黄）
- **文件路径输出**：必须在最终回复中输出完整的文件路径，使用 Markdown 超链接样式：`[文件名](file://完整路径)`，确保用户可以直接点击定位文件

## 十、注意事项

1. **脚本零内置规则**：`load_data()` 无 `track_rules` 时所有词归为「品类通用」
2. **模型负责归纳**：每次调用前必须先分析数据、临时归纳赛道
3. **只取前8赛道**：`get_track_stats(max_tracks=8)` 会自动把第9个及以后归为「其他」
4. **赛道定义可选**：无定义时策略字段留空，不影响数据Sheet生成
