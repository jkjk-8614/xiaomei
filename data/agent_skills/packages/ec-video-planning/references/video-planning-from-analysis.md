# 视频策划生成规则

本文件在生成新的视频策划时读取。输入可以是 `video-analysis` 详细分析报告、视频脚本拆解结果、用户上传视频的拆解结果，或用户提供的产品/品牌信息。

## 输入解析

如果输入是详细分析报告，优先提取：

- 视频基础信息：时长、画幅、平台适配、采样和辅助产物。
- 执行摘要：原视频核心信息、目标、优势和最大问题。
- 时间线拆解：每段的画面、文案、功能和备注。
- 视觉识别结果：关键文案、产品外观、动作、构图、可读性问题。
- 节奏与情绪：开头、中段、结尾节奏，情绪调性和传播意图。
- 叙事结构：钩子、铺垫、证明、价值传递、行动号召。
- 优势、问题、风险、优化建议。
- 证据记录和评分 Rubric。

如果输入是脚本拆解结果，提取镜头时间、画面描述、口播、字幕、运镜和整体风格。

如果输入只有视频，先完成基础拆解，再基于拆解生成策划。

## 策划原则

新视频策划不是复述原视频。必须完成三件事：

1. 继承原视频有效资产：可保留产品记忆点、风格、卖点、有效镜头或节奏段。
2. 修复原视频问题：把分析报告中的问题和优化建议转为新策划动作。
3. 强化传播目标：明确平台、受众、卖点、转化目标和 CTA。

无法确认的产品参数、价格、活动、品牌约束、真实功效证明，统一写为“待用户确认”。

## 分镜硬规则

- 每个镜头描述必须 50 字以上。
- 分镜时间范围必须连续，不要留下空档。
- 建议短视频默认 12-20 秒；如果用户指定时长，严格按用户指定时长规划。
- 开场 1-3 秒必须有明确钩子，不能只做普通展示。
- 中段必须有卖点证明，不只说卖点。
- 结尾必须有行动号召或品牌落版，除非用户明确不要转化。
- 每个镜头必须包含画面、口播或无口播说明、字幕呈现、拍摄执行。

## 从分析报告转化为策划动作

常见转换方式：

- “开场钩子弱” -> 开头使用强动作、强问题、强反差、强利益点或核心结果预览。
- “字幕可读性一般” -> 放大字号、加描边/底条、减少单屏字数、延长停留时间。
- “缺少 CTA” -> 结尾加入购买、咨询、查看详情、关注、领取权益等行动提示。
- “缺少场景” -> 增加真实使用场景、全身穿搭、环境对比或前后效果。
- “证明不足” -> 增加测试、对比、特写、动作演示、数据或用户证据。
- “节奏偏平” -> 增加镜头速度变化、动作节点、音效卡点、转场或视觉反差。
- “音频弱” -> 补充音乐、音效、口播节奏和关键动作声音。

## 文案规则

- 口播要自然，适合短视频表达，不要像产品说明书。
- 字幕要短、可读、强信息层级。
- CTA 要具体，不要只写“快来看看”。
- 如果是电商产品，优先突出用户利益、使用场景、证明和购买理由。
- 如果缺少真实价格、优惠或活动信息，写“价格/活动待确认”，不要编造。

## 平台适配建议

- 抖音/快手/TikTok/Reels：优先 9:16，强钩子，快节奏，字幕大，CTA 清楚。
- 小红书：可更重视质感、场景、生活方式、真实体验。
- 电商详情页：产品细节、功能证明、参数和购买理由要更完整。
- YouTube/横屏广告：可增加叙事铺垫和环境镜头。

## 完整性要求

- 如果输入报告有明确问题和建议，策划中必须回应这些点。
- 如果用户给了品牌、受众、平台或产品信息，优先使用用户信息。
- 如果用户只给了分析报告，没有新产品信息，就基于原产品生成改进版视频策划。
- 不要凭空声称有真实数据、真实用户反馈或真实功效证明。
