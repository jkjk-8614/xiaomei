# 白底产品图优化规则

本文件只在视频策划结果已经输出，且用户明确选择“白底产品图优化”时读取。

## 触发条件

仅当用户选择：

- `2`
- `白底产品图优化`
- 上传新产品白底图并要求替换产品

才进入本流程。

## 步骤 1：请求白底图

如果用户还没有上传新产品白底图，提示：

```markdown
## 请上传新产品的白底图

要求：
- 白色背景，纯白或接近白色
- 清晰展示产品正面或侧面
- 光线均匀，无阴影遮挡
```

## 步骤 2：分析白底图

使用当前对话模型分析白底图中的新产品，生成外观描述。重点记录：

- 产品品类
- 整体轮廓
- 正面 / 侧面结构
- 材质、纹理、反光
- 颜色、图案、logo 位置
- 尺寸比例和可见细节

记录白底图路径到 `replacement_image_paths`。这些路径用于后续保持产品理解一致性；如果用户后续选择“生成视频”，必须把 `replacement_image_paths` 中的全部图片路径传给 Seedance 的 `--ref` 参数，不要只选其中一张。

## 步骤 3：重写视频策划

基于当前视频策划结构和新产品外观，重新生成视频策划。

硬规则：

- 严格保持当前策划时间轴完整性。
- 严格保持镜头数量。
- 每个镜头时间范围必须与当前策划一致。
- 每个镜头描述仍然必须 50 字以上。
- 仅替换产品描述。
- 环境、场景、运镜、人物动作、口播、字幕和时间范围保持不变，除非用户明确要求同步调整。
- 禁止压缩、跳过或合并任何时间段。
- 输出中必须保留 `replacement_image_paths` 列表，便于后续视频生成完整引用用户上传的全部产品白底图。

## 输出

输出优化后的完整视频策划结果。输出后询问：

```markdown
### 接下来要做什么？

回复选项：
- 生成视频：使用优化后的视频策划生成视频
- 跳过：仅保存优化后的视频策划
```
