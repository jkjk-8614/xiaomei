# 视频分析与脚本拆解输出规则

本文件只在输入是视频、且需要先完成视频拆解分析时读取。

## 分析方式

默认使用当前对话模型分析视频内容：

- 先提取序列帧。
- 再基于关键帧与完整帧序列进行视觉分析。
- 最后输出结构化视频分镜拆解结果，并将其作为生成新视频策划的依据。

如果用户提到 minimax、kimi 等模型，优先遵循当前会话可用模型能力，不切换到其他独立分析脚本。

## 重点观察帧

- 首帧
- 中间关键帧
- 结尾帧
- 动作或镜头变化明显的帧
- 字幕、产品、人物表情或口播变化明显的帧

必要时结合完整序列帧核对动作连续性。

## 分析维度

逐帧分析时记录以下维度，用于生成 50 字以上的镜头描述：

- 主体静态：人物外貌、衣着材质纹理、配饰细节、发型妆容。
- 主体动态：核心动作、姿态变化、嘴型眼神变化、呼吸起伏、手部动作。
- 表情分析：眉毛形态、眼神方向、嘴角弧度、面部肌肉变化。
- 服装配饰动态：衣物飘动、配饰晃动、材质反光变化。
- 环境动态：背景元素动效、光影变化、景深变化。
- 运镜判断：固定、推、拉、摇、移、跟、环绕，以及速度、幅度、节奏。
- 口播配音：人声内容、语调情绪、语速节奏、配音风格。
- 字幕呈现：字幕内容、字体风格、出现动画、位置排版。

## 运镜判断 4 步流程

必须执行：

1. 观察开头帧和结尾帧中，人物或主体大小是否变化。
2. 判断是镜头推拉还是人物自己靠近：对比背景物体是否同步变化。
3. 如果人物大小不变，观察背景物体是否发生位移。
4. 仍无法判断时，用开头帧和结尾帧分别与中间帧逐一对比。

无法确认时明确标注为“推测”，不要编造确定结论。

## 镜头描述硬规则

每个镜头描述必须 50 字以上，并包含尽量多的以下细节：

- 人物 / 主体的具体动作、姿态变化。
- 表情细节，如眉毛、眼神、嘴角、面部肌肉。
- 服装材质、配饰动态。
- 环境元素变化，如光影、背景物体、景深。
- 镜头运动的具体方式、速度、方向、幅度。
- 画面氛围和情绪传达。
- 口播配音内容、语调情绪、语速节奏。
- 字幕内容、字体风格、出现方式、位置排版。

## 输出格式

使用以下中文结构：

```text
【镜头 1 | 0s-Xs | 运镜方式】
[该时间段内的完整画面和动作描述，50字以上，包含主体动作细节、表情变化、服装配饰动态、环境光影变化、镜头运动特征、氛围情绪]

【口播配音 | 0s-Xs】
[配音内容原文、语调情绪、语速节奏；没有明显口播时写“未识别到明确口播”]

【字幕呈现 | 0s-Xs】
[字幕内容摘要、字体风格、出现动画、位置；没有字幕时写“未识别到明显字幕”]
```

根据实际分析继续添加更多镜头。每个镜头描述都必须 50 字以上，口播配音和字幕呈现按实际情况添加。

## 完整性要求

- 原视频有多少秒，脚本拆解结果就必须覆盖多少秒，除非用户明确指定只分析片段。
- 不要跳过任何明显镜头变化。
- 时间范围必须连续，尽量不要留下空档。
- 镜头切分应基于画面变化、动作变化、运镜变化、口播段落或字幕变化，不要机械平均切分。
- 无法听清或看清的内容要说明不确定性。
