# 视频工具执行说明（通用）

## 边界

本说明只负责把视频策划转成可执行的分镜、提示词、素材映射和验收记录，不绑定特定 CLI、宿主工作区、宿主工具协议、API、账号或保存目录。实际生成由当前宿主提供的视频工具完成。

## 执行流程

1. 确认产品素材、参考视频/帧、人物或场景素材以及各自的角色和授权边界。
2. 按分镜逐镜整理时长、画面主体、动作、镜头运动、字幕、音频和转场；提示词中明确哪些内容来自产品锚点素材。
3. 当前宿主支持时，可选择 Kling、Seedance 等模型；模型名只是可选参数，不代表本技能已经调用或完成生成。
4. 按镜头顺序提交任务并记录任务标识、输入素材、提示词版本、输出位置和失败原因。宿主没有批量能力时逐镜执行。
5. 检查产品一致性、动作连续性、时长、字幕安全区、画面比例、审核风险和音画同步；不合格镜头单独修订。

## 宿主没有视频工具时

交付完整分镜脚本、口播和字幕、镜头提示词、素材清单、参数建议、剪辑顺序和质检清单；不得伪称视频已经生成。

## 交付记录

建议记录输入素材、镜头编号、完整提示词、可选模型和参数、输出路径、质检结果与后续剪辑动作。
