# 视频策划生成 CH

用于基于视频、视频脚本拆解结果，或 `video-analysis` 产出的详细分析报告，生成新的中文视频策划。主体架构沿用 `宿主工具接口`：先产出结构化结果，再询问用户是否继续生成视频或做白底产品图优化。

## 默认行为

- 默认中文输出。
- 默认先生成新的视频策划结果，再询问后续操作；不要在一开始让用户选择模式。
- 默认兼容 `video-analysis` 的详细分析报告 Markdown 文件，包括视频基础信息、时间线拆解、视觉识别结果、节奏情绪、问题风险、优化建议和证据记录。
- 如果用户提供的是详细分析报告，优先基于报告中的结论、问题和优化建议生成新视频策划，不必重新分析原视频。
- 如果用户提供的是视频而不是分析报告，先按参考 skill 架构提取序列帧并完成脚本拆解，再基于拆解结果生成新的视频策划。
- 默认对外使用“视频策划”“新视频脚本”“分镜策划”等中文表述，不使用“反推词”“模式 A/B”等旧术语。
- 生成视频时如果参考帧、参考视频或上传素材中包含清晰人物、人脸、真人口播、明星/名人形象，应提前标记审核风险；不要在任务失败后沉默。

## 输入与触发

支持以下输入：

- `video-analysis` 生成的详细分析报告，例如 `<视频名>-analysis.md`。
- 用户粘贴的详细视频分析报告全文。
- 用户上传的 `mp4`、`webm`、`mov` 等视频。
- 既有视频脚本拆解结果。
- 产品信息、品牌信息、目标平台、时长、受众、卖点、风格偏好等补充要求。

当用户表达以下需求时使用：

- `/视频策划`
- `/视频脚本ch`
- `ec-video-planning`
- 根据分析报告生成视频策划
- 根据详细分析报告写新脚本
- 参考这个视频分析做新视频方案
- 生成视频脚本 / 分镜脚本 / 口播字幕
- 根据拆解结果优化成新的视频策划

## 标准工作流

1. 判断输入类型：
   - 如果是 `video-analysis` 详细分析报告，读取并提取报告中的视频事实、卖点、时间线、视觉识别结果、节奏情绪、问题风险和优化建议。
   - 如果是视频文件，按 2fps 提取序列帧，分析完整视频，并输出脚本拆解基础结果。
   - 如果是既有脚本拆解结果，直接提取镜头结构、口播、字幕、运镜和风格。
2. 读取 `references/video-planning-from-analysis.md`，生成新的中文视频策划。
3. 输出结构化视频策划结果，包含策略摘要、创意方向、分镜脚本、口播配音、字幕呈现、运镜建议、拍摄执行建议和优化理由。
4. 策划完成后询问用户下一步：
   - 生成视频
   - 白底产品图优化
   - 跳过

## 视频输入时的序列帧提取

当输入是视频文件时，默认按参考架构执行：

```bash
ffmpeg -i <video_path> -vf "fps=2" -frames:v <帧数> -y <output_path>/frame_%04d.jpg
```

输出到视频同目录的 `<video_name>_frames/` 文件夹。帧数根据视频时长自动计算；用户指定时间范围时，按范围调整命令。

## 分析报告输入兼容

当输入是 `video-analysis` 生成的详细分析报告时，必须优先使用报告内容作为策划依据。重点提取：

- 原视频类型、主题、可能目标。
- 关键画面文案和非文字视觉证据。
- 时间线结构和镜头功能。
- 节奏、情绪、视觉、剪辑、叙事和平台适配结论。
- 优势、问题、风险和优化建议。
- 评分 Rubric 和证据记录。

策划时要明确“沿用什么、修正什么、强化什么”，不要只复述原报告。

## 策划与输出规则

读取 `references/video-planning-from-analysis.md`，并严格遵循其中的策划结构、分镜要求、口播字幕规则和优化说明。

核心硬规则：

- 新视频策划必须有明确目标平台、目标受众、核心卖点和转化目标。
- 每个分镜描述必须 50 字以上。
- 分镜时间线必须连续覆盖建议总时长。
- 必须包含口播配音、字幕呈现、画面/动作、运镜、情绪节奏、拍摄执行建议。
- 如果输入来自详细分析报告，必须把报告中的关键问题转化为策划改进点。
- 无法确认的产品、品牌、价格、活动信息要写为“待用户确认”，不要编造。

## 白底产品图优化

仅在视频策划结果输出后，且用户明确选择“白底产品图优化”时执行。读取 `references/white-background-product-rewrite.md`。

默认目标：

- 分析用户上传的新产品白底图。
- 保持新视频策划的时间轴、镜头数量、场景、运镜、口播和字幕结构不变。
- 只替换产品描述，并重新输出完整视频策划。

## 视频生成

用户确认后，将已确认的分镜脚本、产品锚点素材、参考帧和完整视频提示词交给当前宿主的视频工具。宿主支持时可选择 Kling、Seedance 等模型；本 skill 不调用特定软件，也不把规划结果写成已生成视频。宿主不支持视频工具时，输出逐镜提示词、素材映射、参数建议、剪辑顺序和质检清单。

## 完成后的默认追问

视频策划输出完毕后，追加：

```markdown
### 接下来要做什么？

回复选项：
- 1 或 生成视频：使用 Seedance 2.0 全能参考模式生成视频
- 2 或 白底产品图优化：上传新产品白底图，在当前策划结构基础上替换产品并重新输出视频策划
- 3 或 跳过：仅保存视频策划结果，不继续处理
```
