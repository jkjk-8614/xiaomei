# 平台倾向

同一商品在不同平台的主图不一定相同。先判断目标平台，没有明确时默认淘宝/天猫，并注明假设。

## 淘宝 / 天猫

重视搜索点击、商品质感、卖点清晰、人群标签精准、套图专业度、品类主图规范。

适合：

- 视觉干净
- 产品突出
- 卖点明确
- 文字有层级
- 不过度杂乱

## 拼多多

重视利益点、性价比、促销感、分量感、对比感、快速理解。

适合：

- 信息密度更高
- 文案更直给
- 价格/规格/赠品/数量感明显
- 清楚有冲击，但不能廉价混乱

## 抖音电商

重视推荐流停留、场景吸引、情绪触发、短视频封面感、人群代入、第一眼冲击。

适合：

- 强生活场景
- 强情绪画面
- 像内容封面
- 人物/手持/使用中场景更重要

## 小红书

重视审美标签、生活方式、真实分享感、种草感、人群身份感。

适合：

- 不要太硬广
- 风格精准
- 画面让人有“我也想拥有”的感觉
- 字体和贴纸可以更轻内容化

## 输出字段

- 目标平台
- 平台流量类型：搜索 / 推荐 / 内容种草 / 低价转化
- 主图信息密度
- 审美强度
- 文案强度
- 场景强度
- 促销强度
