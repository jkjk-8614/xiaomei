# 参考图与竞品图分析

参考图不是“照着做”，而是提炼可迁移价值。

## 类型判断

- 自家现有主图套图：看当前主图1-5的转化任务、卖点重复、视觉一致性、点击力和改版机会。
- 竞品主图套图：看竞品1-5张如何组织点击、信任、卖点证明、顾虑回应和收口，不把竞品商品事实当成本商品事实。
- 同品类竞品：看行业结构、卖点表达、构图、文案、产品占比、同质化。
- 跨品类风格参考：看色调、光影、留白、字体、标签、情绪、画面节奏。
- 字体排版参考：看标题层级、标签样式、信息密度、安全区。
- 场景参考：看生活方式、空间气质、人物状态、道具关系。
- 光影参考：看光线方向、阴影、背景质感、反光控制。

## 跨品类转译原则

- 借鉴风格，不借鉴产品。
- 借鉴布局，不改变商品。
- 借鉴光影，不复制错误场景。
- 借鉴字体，不复制品牌。
- 借鉴情绪，不复制品类元素。

例：香水图给椅子参考时，可借鉴黑金高级色调、侧逆光、大面积留白、简洁衬线字体、高端品牌广告感；不能借鉴香水瓶造型、香氛道具或不适合椅子的摆放逻辑。

## 5张主图套图分析

当用户上传一组约5张主图时，必须按“套图”分析，而不是只做单张参考图分析。

### 套图资产判断

- 自家现有主图：用于诊断当前问题和改版方向。
- 竞品主图：用于拆解对方打法和寻找差异化机会。
- 未说明归属：标为待确认，但仍可先分析图序和表达方式。

### 逐图拆解表

| 图序 | 推测任务 | 主视觉/产品占比 | 核心文案 | 信息层级 | 优点 | 问题/风险 | 可转译方向 |

| 主图1 | 点击/人群筛选 |  |  |  |  |  |  |
| 主图2 | 产品确认/信任 |  |  |  |  |  |  |
| 主图3 | 卖点证明 |  |  |  |  |  |  |
| 主图4 | 顾虑回应/场景 |  |  |  |  |  |  |
| 主图5 | SKU/收口/补充信任 |  |  |  |  |  |  |

### 套图总评

- 图序是否形成转化递进。
- 是否所有图都在重复同一个卖点。
- 主图1是否有足够点击理由。
- 后续图是否覆盖信任、顾虑、场景、规格/SKU。
- 中文文字是否小图可读。
- 风格、字体、标签是否统一。
- 竞品图中哪些只能借鉴结构，不能借鉴事实、品牌、认证、商品元素。
