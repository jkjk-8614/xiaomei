# 用户顾虑与卖点映射

顾虑分析是主图策略的核心。用户不买，往往不是因为没看到卖点，而是因为担心买错。

## 来源优先级

1. 用户提供的评价/问大家/差评/中评
2. 竞品评价和问答
3. 用户口述的售前疑问
4. 品类常识

## 常见顾虑映射

| 顾虑 | 常见品类 | 主图回应方式 |
|---|---|---|
| 不稳/不耐用 | 家具、工具、运动器材 | 结构展示、承重场景、细节特写 |
| 色差/质感廉价 | 家具、鞋服、美妆包装 | 自然光实拍质感、材质特写 |
| 尺寸不合 | 家具、收纳、服饰 | 尺寸对比、场景比例、人手/空间参照 |
| 不新鲜/分量少 | 食品农产品 | 产地、切面、分量摆放、冷链/现发 |
| 不安全/有味道 | 母婴、个护、家具 | 材质依据、检测/标准、柔和可信画面 |
| 不兼容 | 3C配件 | 兼容型号、接口/结构展示、参数区 |
| 接口/协议误解 | 3C配件、扩展坞 | 端口示意、使用前提、设备连接场景 |
| 发热/供电担心 | 3C配件、充电器 | 克制说明散热设计、功率前提、避免绝对承诺 |
| SKU选错 | 多规格标品、3C配件 | 选型图、当前SKU高亮、差异表 |
| 不好搭 | 服饰、家具、家居 | 多场景搭配、目标人群生活方式 |
| 显廉价 | 高客单审美品 | 留白、材质、克制光影、减少促销元素 |

## 注意

- 能用画面回应的顾虑优先画面化。
- 不能证明的硬卖点不要写成事实，可写成“预留文案区，由用户确认后添加”。
- 顾虑不一定都要放图上，优先处理影响转化最大的3个。
- 来自评价/问大家的顾虑要标注高频程度；不要只罗列，要映射到具体图序。
