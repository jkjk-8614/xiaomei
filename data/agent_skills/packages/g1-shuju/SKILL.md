# G1-自己店铺·数据深度诊断分析

通用类目技能。根据输入的生意参谋商品排行CSV，生成21Sheet深度诊断Excel报告。技能不绑定特定类目，支持自定义词库。

**用法:**
```bash
python build_G1.py --input "数据.csv" --output "输出目录" --shop-name "店铺名"
```

**可选参数:**
- `--word-hints`: 自定义词根关键词（逗号分隔，如 "连衣裙,套装,公主"）
- `--fabric-hints`: 自定义面料/材质关键词（逗号分隔，如 "棉,雪纺,蕾丝"）

**注意:** 生成的产物内容需严格和技能中的参考示例对标。

## 二、分析思维

对自己店铺进行21维度深度诊断:KPI/退款率/类目/面料/爆款/僵尸链接/推广/词根等

## 三、呈现逻辑

21Sheet:报告目录→KPI→退款率→类目→面料/材质关键词→爆款→高退款→推广→僵尸链接→词根→行动建议→TOP1诊断→推广费占比→类目×推广→推广明细→退款后推广→退款率总览→类目×退款→退款明细→损失分析→数据看板

- **4-面料材质分析**: 默认自动从标题提取高频词；若提取质量不足则使用通用面料词库；支持 `--fabric-hints` 自定义
- **9-词根分析**: 默认自动从标题提取高频词；若提取质量不足则使用通用词库；支持 `--word-hints` 自定义
