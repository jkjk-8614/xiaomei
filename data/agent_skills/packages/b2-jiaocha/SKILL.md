# B2-交叉矩阵·交叉赛道四级分类

根据输入的交叉赛道数据，将交叉赛道按买家数分为头部/腰部/动销/尾部四级，制定不同的运营策略。生成产物需严格和技能中的参考示例对标。

## 一、技能信息

| 项目 | 内容 |
|:---|:---|
| **技能编号** | B2 |
| **技能名称** | 交叉赛道四级分类 |
| **所属阶段** | B2-交叉矩阵 |
| **核心数据源** | B1技能输出表格（交叉赛道整合数据） |
| **输出格式** | Excel（8个Sheet） |

## 二、分析思维

将交叉赛道按买家数分为头部/腰部/动销/尾部四级，制定不同的运营策略：
- **头部（TOP1-10）**：高买家数+高CVR，优先投放+壁垒建设
- **腰部（TOP11-30）**：中等买家数，差异化投放+延伸路径
- **动销（TOP31-50）**：低买家数+有转化，测试投放+观察指标
- **尾部（TOP51+）**：极低买家数，储备观察+暂不投放

## 三、呈现逻辑

8 Sheet：
1. **四级赛道总览**：四级分类汇总表 + 10类型×4级矩阵 + 全量赛道排序TOP50
2. **头部赛道明细**：TOP1-10赛道详细数据 + 3维归属 + 差异化策略
3. **腰部赛道明细**：TOP11-30赛道详细数据 + 3维归属 + 差异化策略
4. **动销赛道明细**：TOP31-50赛道详细数据 + 3维归属 + 差异化策略
5. **尾部赛道明细**：TOP51+赛道详细数据 + 3维归属 + 差异化策略
6. **全量赛道整合**：全部赛道按四级分类整合，赛道色系着色
7. **策略执行建议**：4板块策略建议 + 去垄断TOP5赛道
8. **指标说明手册**：核心指标说明 + 四级分类定义 + 竞争评级定义

## 四、执行步骤

### Step 1: 接收用户输入

确认以下信息：
1. **品类名称**（如"行李箱(侧开盖赛道)"）
2. **全品类总买家数**（用于计算买家占比%）
3. **数据源文件路径**（B1输出的交叉赛道整合Excel）
4. **输出目录**

### Step 2: 准备交叉赛道数据源

数据源应为Excel文件，包含一个`交叉赛道数据源`sheet，列结构如下：

| 列名 | 说明 |
|:---|:---|
| 类别A | 第一类词根类别（如🔴功能/🟠材质/🟡人群/🟢场景/🔵款式） |
| 词根A | 第一类词根 |
| 类别B | 第二类词根类别 |
| 词根B | 第二类词根 |
| 类别C | 第三类词根类别（3维交叉时填写） |
| 词根C | 第三类词根（3维交叉时填写） |
| 交叉类型 | 2维 / 3维 |
| 共现词数 | 含2/3类词根的搜索词数量 |
| 总搜索人气 | 交叉赛道内搜索词预估搜索人气之和 |
| 总买家数 | 交叉赛道内搜索词预估支付买家数之和 |
| 平均CVR% | 赛道内搜索词平均支付转化率 |
| 平均供给比 | 赛道内搜索词平均需求供给比 |
| 竞争评级 | 🔵蓝海/🟢轻竞争/🟡中竞争/🟠高竞争/🔴红海/⚪数据缺失 |
| 3维归属 | 该记录所属的三维组合（如功能×场景×款式） |
| 差异化策略 | 该记录的差异化定位策略 |
| 交叉组合 | 交叉组合标签（如🟢登机×🔵款式） |

**注意**：一条2维交叉组合可能对应多条记录（每条对应不同的3维归属），脚本会保留所有记录进行排序和分级。

### Step 3: 生成配置文件

创建 `b2_config.json`：

```json
{
  "input_path": "表格/B1输出.xlsx",
  "output_path": "表格/[品类]_B2_交叉赛道四级分类.xlsx",
  "category_name": "行李箱(侧开盖赛道)",
  "total_buyers": 716438,
  "sheet_name": "交叉赛道数据源",
  "tier_thresholds": {
    "head": 10,
    "waist": 20,
    "active": 20
  }
}
```

**阈值配置说明**：
- `tier_thresholds` 为可选配置，省略时使用默认值（头部10/腰部20/动销20）
- 支持**绝对数量**模式：`{"head": 10, "waist": 20, "active": 20}`
- 支持**比例模式**（值<1）：`{"head": 0.08, "waist": 0.25, "active": 0.40}`，基于总记录数自动计算

### Step 4: 执行脚本

```bash
python /技能目录/build_B2.py --config b2_config.json
```

### Step 5: 输出结果

在最终回复中输出完整的文件路径，使用 Markdown 超链接样式：
```
报告已生成：[品类_B2_交叉赛道四级分类.xlsx](file://完整路径)
```

## 五、数据源要求

- B1技能输出表格，或按上述格式准备的交叉赛道整合数据
- 必须包含：类别A/B、词根A/B、交叉类型、共现词数、总买家数、竞争评级、3维归属
- 建议包含：平均CVR%、平均供给比、差异化策略、交叉组合

## 六、输出规范

- **文件名格式**: `[品类]_B2_交叉赛道四级分类.xlsx`
- **Sheet命名**: 按呈现逻辑中的8 Sheet结构
- **样式规范**: 
  - 标题行：深蓝底(FF204060) + 白字
  - 表头：深绿底(375623) + 白字
  - 头部数据行：浅红底(FFFFE8E8)
  - 腰部数据行：浅橙底(FFFFF0D0)
  - 动销数据行：浅蓝底(FFE0F0FF)
  - 尾部数据行：浅灰底(FFE8E8E8)
- **文件路径输出**：必须在最终回复中输出完整的文件路径，使用 Markdown 超链接样式：`[文件名](file://完整路径)`，确保用户可以直接点击定位文件

## 八、关联技能

- **上游输入**: B1-三维交叉整合定位
- **下游输出**: C1-评价需求深度分析

## 九、差异化策略生成

脚本支持两种差异化策略来源：

1. **数据源自带**：输入数据中已填写差异化策略列，直接保留
2. **自动推断**：基于3维归属自动生成，并叠加竞争评级增强

### 自动推断逻辑

| 3维归属 | 基础策略 |
|:---|:---|
| 功能×场景×款式 | 功能卖点+场景痛点+款式差异三维定位 |
| 材质×人群×款式 | 材质质感+人群偏好+款式选择三维定位 |
| 人群×场景×款式 | 人群专属+场景触发+款式偏好三维定位 |
| ... | ... |

### 竞争评级增强

| 竞争评级 | 策略增强后缀 |
|:---|:---|
| 🔵蓝海 | \| 蓝海赛道：快速占位，建立先发优势 |
| 🟢轻竞争 | \| 轻竞争赛道：优化词根布局，抢占搜索流量 |
| 🔴红海 | \| 红海赛道：强差异化切入，避免正面竞争 |

## 十、策略建议颗粒度

策略执行建议（Sheet7）按四级×竞争评级矩阵生成精细化行动建议：

| 等级 | 蓝海策略 | 轻竞争策略 | 红海策略 |
|:---|:---|:---|:---|
| 头部 | 立即抢占，加大投放 | 优先投放，优化词根 | 避免投放，寻找细分 |
| 腰部 | 快速跟进，承接溢出 | 差异化切入，错位竞争 | 放弃切入 |
| 动销 | 潜力挖掘，加大测试 | 稳步测试，关注ROI | 暂缓投入 |
| 尾部 | 关注储备，持续监测 | 定期复盘，60天评估 | 直接放弃 |

## 十一、使用场景

B1输出后，对交叉赛道进行优先级分级和运营策略制定，识别头部壁垒赛道、腰部延伸赛道、动销测试赛道和尾部储备赛道。

## 十二、注意事项

1. 四级分类阈值（头部10/腰部20/动销20）可根据品类规模调整，支持绝对数量和比例两种模式
2. 数据质量直接影响分析结果，务必确认数据源中总买家数准确
3. 同一条2维交叉组合可能对应多个3维归属变体，脚本会保留所有变体进行排序
4. 输出前务必检查Sheet1的10类型×4级矩阵分布是否合理
5. 差异化策略自动推断仅在没有数据源自带策略时触发，已有策略优先保留
