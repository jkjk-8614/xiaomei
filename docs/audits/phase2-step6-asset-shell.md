# 第二阶段第六步：资源管理、公共工具与界面壳

日期：2026-11-09

这一步把素材目录、本地路径、设置页保存记录，以及预览、历史多选、主题这些公共决定收进独立模块。页面外观、旧脚本和用户目录都还在。默认不带开关时，请求不会带新头部，素材页和设置页仍走原来的函数。

CainFlow、商品分析、SKU、批量生成、电商工作台、`LICENSE` 和版权声明没有改。没有扫描或覆盖用户素材。

## 来源与做法

现网约定保持这些口径：

- 资产库至少留一个。默认库补一个工作流分组，旧的单层 `categories` 仍能读成默认库。条目按创建时间新的在前。旧的扁平数字人字段折进 `registrations`。
- 分组移动只在相同类型之间进行。删除前仍由原来的引用检查和回收站处理文件，新模块只负责目录里哪些条目要摘掉。
- 本地路径不允许跳出素材根目录。上传文件名仍去掉不安全字符，并避免扩展名叠两次。
- 设置页保存仍提交现在的平台字段。模型列表只保留用户已经写下的名称，不在这里写死一份新的模型下拉。即梦、GPT CLI、Antigravity CLI 的原有默认模型规则继续生效。
- 图片筛选、滚轮预览、历史批量选择和主题外观沿用现在的结果：查询词都要命中，预览围绕指针缩放，旧的默认蓝迁到现在的青色。

新文件是 `asset_kernel.py` 和 `static/js/xiaomei-shell-kernel.js`。对照当前仓库里仍保留的大熊同源素材、设置和壳层脚本，新文件没有连续 8 行相同的规范化代码，最长相同行是 3 行。

`python3 -m unittest tests.test_asset_kernel` 与 `node --test tests/xiaomei-shell-kernel.test.cjs` 已通过。

## 开关与回滚

| 操作 | 结果 |
| --- | --- |
| 什么都不做 | `data-xm-assets="legacy"`，素材和设置请求不带新头部 |
| `?xmAssets=1` 或 `next` | 写入 `localStorage['xiaomei.assetKernel']='next'`。之后这些页面的素材、本地素材和平台保存请求带 `X-Xiaomei-Assets: next` |
| `?xmAssets=0` 或 `legacy` | 回到旧函数 |
| `XiaomeiShellKernel.setActive(false)` 后刷新 | 同上 |

服务端只在这个请求头等于 `next` 时改用新模块。前面五步的 `xmViewport`、`xmNodes`、`xmHistory`、`xmDocument`、`xmDispatch` 仍然各自独立。

浏览器采集插件和 Photoshop 连接器的旧目录没有删除。开关打开后，画布和素材页提交给素材接口的请求体由新模块组装，字段仍是现在的 `library_id`、`category_id`、`folder` 和 `items`。发行清单里拿掉旧连接器要等全部验收通过，不在这一步做。

## 最小适配层

真正落盘、回收站和密钥保存仍在原来的函数里。开关打开时：

- `main.py` 的资产库整理、分组移动和删除计划、路径检查、存储目录判断、上传文件名、分类字段清洗改走 `asset_kernel`。
- `static/js/asset-manager.js` 的多选和批量移动、删除、复制、导入请求体改走新模块。
- `static/js/api-settings.js` 保存平台时，用新模块生成提交记录。界面布局和样式表没有换。
- `static/js/smart-canvas.js` 与 `static/js/canvas.js` 的素材侧栏、保存和删除请求使用同一套目录和请求体。
- `static/js/image-space.js`、`image_space.py` 的筛选，`theme.js` 的外观和缩放，`image-preview.js` 的滚轮，`history-bulk-manager.js` 的多选，在开关打开时改走新模块。
- 素材页、设置页、应用壳、两套画布，以及带历史批量或预览的页面，会在原脚本之前加载新模块。

## 手工验收

1. 不带参数打开素材页和 API 设置。`document.documentElement.dataset.xmAssets` 为 `legacy`。分类、上传、移动、删除和平台保存应与现在一致。
2. 加上 `?xmAssets=1` 后刷新。再做一次分组移动、本地文件夹操作和平台保存。模型列表应仍是账号里已有的模型，不能出现一份写死的新名单。
3. 打开经典画布或智能画布的素材侧栏，确认分类和图片筛选仍能找到原来的素材。
4. 在在线生图页看一次大图滚轮，并进入历史批量选择后全选再退出。主题如果改成深色，刷新后仍是深色。
5. `?xmAssets=0` 刷新后，上述操作回到旧函数。确认没有改用户目录里的素材和历史。

本环境跑了目录、路径和设置记录的单测，没有用真实平台密钥保存配置，也没有改本机素材目录。请在本机用已有素材库走一遍。
