安装 / 更新方法

Windows：在小美画布文件夹中打开 CLI → windows → jimeng，按以下顺序操作。安装需要联网。

  1. 首次使用 WSL：双击 install_wsl_ubuntu.bat，按提示允许管理员权限；如需重启电脑，重启后打开 Ubuntu，完成用户名和密码设置。已有可用的 Ubuntu 可跳过。
  2. 双击 install_jimeng_cli.bat 安装或更新即梦 CLI，等待窗口提示完成。
  3. 完全退出并重新打开小美画布，点击“重新检测”，显示“未登录”后点击“扫码登录”。也可双击 login_jimeng_cli.bat 登录。

也可在小美画布文件夹中打开 PowerShell，运行安装脚本：

.\CLI\windows\jimeng\install_jimeng_cli.bat

安装失败时，查看小美画布 logs 文件夹中最新的 jimeng-cli-install-*.log。

macOS：运行 CLI/macos/jimeng/install_jimeng_cli.command，完成后运行同目录的 login_jimeng_cli.command，再重启小美画布。
