# 文件图标

`xmind.png` 来自 XMind 桌面应用图标。`wps.png`、`wps-sheet.png` 和 `wps-presentation.png` 来自 WPS Office 的文字、表格、演示文件图标资源。

Word、Excel、PowerPoint 和 PDF 使用 Microsoft Fluent 的文件类型图标：

- [Word](https://static2.sharepointonline.com/files/fabric/assets/item-types/48/docx.svg)
- [Excel](https://static2.sharepointonline.com/files/fabric/assets/item-types/48/xlsx.svg)
- [PowerPoint](https://static2.sharepointonline.com/files/fabric/assets/item-types/48/pptx.svg)
- [PDF](https://static2.sharepointonline.com/files/fabric/assets/item-types/48/pdf.svg)

图标仅用于标识对应文件类型，品牌归其各自所有者所有。文件扩展名映射由 `static/js/smart-canvas.js` 的 `documentSoftwareIconHtml` 定义。
