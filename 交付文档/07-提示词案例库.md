# 提示词案例库

## 功能定位

“提示词库”只收藏小美画布中已经生成完成、并且带有提示词的图片结果。上传图片、普通素材、视频和音频不会进入案例库。一次生成的多张图片保存为一个案例，当前选中的结果作为封面，其余结果作为变体。

侧栏入口加载 `static/prompt-library.html`。页面使用瀑布流卡片和右侧详情抽屉，支持标题/提示词/标签/模型搜索、分类筛选、标签筛选、最近收藏/最近使用排序、案例编辑、复制提示词、应用到画布和删除。

## 画布交互

生成结果节点的浮动工具栏提供星标按钮。点击后会打开保存表单，标题默认取提示词首行，可填写分类、标签和备注。重复收藏同一批生成结果时，后端按来源媒体 URL 去重并打开原案例。

“应用到画布”通过父页面 `postMessage` 发送到当前画布：有合适的绘画节点时复用，否则在视口中心新建绘画节点。应用只写入提示词、参考图和当前可用的兼容参数，不自动调用模型；操作会写入画布撤销栈。当前没有具体画布时，父页面会把案例暂存 10 分钟，用户打开画布后自动接收一次。

## 数据和接口

- `data/prompt_cases.json`：独立于 `data/prompt_libraries.json` 的案例索引，首次访问接口时自动初始化。
- `assets/prompt_cases/<case_id>/`：案例封面、变体和参考图的独立副本。删除原画布、历史记录或生成日志不会影响案例；删除案例只删除此目录。
- `GET /api/prompt-cases`：列表、搜索、分类和排序。
- `GET /api/prompt-cases/index`：画布按来源媒体 URL 判断是否已收藏。
- `POST /api/prompt-cases`、`PATCH/DELETE /api/prompt-cases/{id}`：保存、编辑和删除案例。
- `POST /api/prompt-cases/{id}/use`：记录应用次数。
- `POST/PATCH/DELETE /api/prompt-cases/categories[/<id>]`：管理案例分类。

现有素材库中的文字提示词功能仍使用原有 API 和 `data/prompt_libraries.json`，界面名称改为“文字模板库”；画布内的“提示词模板库”保持模板含义不变。

## 验收重点

1. 单图、多图均只产生一个案例，多图可以切换变体。
2. 没有 `runPrompt` 或没有完成图片结果的节点不能收藏。
3. 原图路径失效后，案例媒体副本仍然可以查看。
4. 搜索能够命中标题、提示词、标签和模型。
5. 应用案例不会自动生成，且可以撤销；模型/工作流失效时保留提示词并提示用户。
