# MCP 设置

入口为左下角“更多设置 → MCP 设置”。支持添加、编辑、启用/停用、移除配置，以及导入包含 `mcpServers` 对象的 JSON 文件。导入只合并新名称，不覆盖同名服务；检查后点击“保存设置”。

本地服务填写启动命令、JSON 数组形式的参数，可选工作目录和环境变量。远程服务填写 Streamable HTTP 地址和可选请求头。服务软件及其插件需按各自文档安装。

## MCP 市场

在设置窗口切换到“MCP 市场”，输入服务名称并搜索。搜索词发送到 MCP 官方目录，结果可加载更多；网络异常时显示错误，可重新搜索。目录未收录的服务仍可手动添加或导入 JSON。

点击“查看详情”可阅读发布者介绍、项目文档和原始安装配置。选择连接方式后，“添加到我的配置”生成停用的草稿，不自动保存、安装、启动或覆盖同名配置。核对命令、地址、环境变量和请求头后点击“保存设置”；确认可信并准备好依赖后再启用和测试。目录收录不是安全认证。

可自动转换的连接方式由 `mcp_settings.py` 的 `market_item()` 定义；复杂参数或不支持的安装方式保留原始配置供手动填写。npm 草稿使用目录指定版本，测试可能下载和执行第三方代码。远程服务若要求浏览器 OAuth 登录，需使用服务提供的其他受支持鉴权方式，不能仅凭地址连接。PS / Blender 配套插件仍按项目文档安装。

目录入口为 `GET /api/mcp/market`，通过固定官方地址查询，不读取本地密钥、不启动服务。上游地址由 `REGISTRY_URL` 定义。

## 连接测试与配置存储

“测试连接”建立短连接，完成 MCP 初始化并读取工具列表，结束后释放连接和本次启动的进程。它不调用工具，也不代表 Photoshop/Blender 桌面桥接已经就绪。启用表示保存的配置允许测试，并非常驻连接。当前画布 Agent 尚未消费此配置，不会自动执行外部工具。

配置存入 `data/mcp_servers.json`，可包含环境变量与鉴权信息，只在本机设置接口读取，不进入 Git 或发布包。后端在 `mcp_settings.py`，接口为 `GET/PUT /api/mcp/settings` 和 `POST /api/mcp/test`；前端为 `static/js/mcp-settings.js` 和 `static/css/mcp-settings.css`。测试最多等待 30 秒；依赖缺失或连接失败显示相应提示。新增后端路由后需重启应用。
