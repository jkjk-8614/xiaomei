# 产品真实尺寸约束

真实尺寸保存产品本身的物理数据，与输出图片的像素尺寸和画幅分别设置。不会从图片 DPI、截图、场景参照物或人物推算厘米尺度。

## 使用

把产品图片连接到产品保真节点，再将产品保真节点连接到普通 AI 生图节点。尺寸由产品保真节点统一提供。

产品保真节点：在「尺寸与校验 → 真实尺寸」编辑。需要制作或使用保护蒙版时，使用左侧保护区域工具，或在「常用设置」的「画布保护蒙版」选择已有蒙版图片。

1. 开启「真实尺寸约束」，填写实际宽度、高度和已知厚度。未知厚度留空；新数据不接受 0 作为未知。
2. 选择 mm、cm、m 或 in。切换单位只改变显示值，原有物理尺寸不变。支持小数。
3. 选择形状、比例与轮廓锁定项，以及约束方式。输入时在本地更新比例和尺寸预览，不提交模型请求。
4. 在原有生图控件中选择输出画幅。例如 30×40cm 产品可以放在 16:9 图片中，产品正面比例仍为 3:4。
5. 使用下游 AI 生图节点的生图按钮运行。在产品保真节点中查看相对比例报告、原图对比、实际参考图和资源省略原因。

圆形指圆形平面：宽和高均为同一正面直径，修改宽度会同步直径；厚度沿垂直圆面的轴向。它不表示圆柱高度。矩形和长方体的宽、高为正面两轴，厚度为前后轴向。

## 约束方式

| 方式 | 实际执行 | 可靠性边界 |
|---|---|---|
| Prompt | 将尺寸、正面比例及勾选的保形要求编译到原提示词后 | 软约束；模型可能忽略，不新增结构参考图 |
| Guide | Prompt 加上本地确定性生成的无文字结构代理图 | 增强软约束；原图负责外观和细节，结构图负责几何，不能保证精确尺寸 |
| Protect | 使用原产品透明通道或保护蒙版，生成背景后在本地合成原产品像素 | 保持原视角、保护核心 RGB 像素；不证明原图符合真实厘米尺寸，也不重新生成侧面结构 |

没有原产品参考图时，Prompt／Guide 仍能传递抽象比例，但不能保证产品身份、外轮廓和外观细节。Protect 必须有原图及有效保护区域。

真实尺寸 Protect 保留用户选择的输出画布，把原产品图居中放入，核心像素不缩放。输出画布不能小于原图；遇到过小的模型输出会停止合成并显示原因。未开启真实尺寸的原有严格保真仍使用其原图画幅规则。

结构代理不是完整产品模型。矩形／长方体提供正面、已知厚度的侧面和简化轴测图；未知厚度时侧面留空、轴测只有平面。圆形提供直径正面与已知厚度的侧面，不补造立体隐藏结构。

## 模型和参考资源

继续使用动态平台和模型列表、现有 GPT Image 2／2.5 编辑请求和 Google Nano Banana／Gemini 图像请求。实际型号与渠道能力由 `product_fidelity.py::capabilities` 判断，代理别名不会被改写为官方型号。字段规则依据 [OpenAI 图片提示与参数](https://developers.openai.com/api/docs/guides/image-prompting) 和 [Google 图像生成接口](https://ai.google.dev/gemini-api/docs/image-generation)，代理通道仍需独立验证。

物理尺寸、锁定开关、比例报告均为应用内部数据。它们不作为虚构的尺寸、ControlNet、mask 或保真参数传给模型。模型收到编译后的提示词，以及该请求模式支持的图片内容。

原始资源角色为 `product_reference` 和 `user_reference`，系统结构资源为 `geometry_reference`。模型请求保留原用户列表的相对顺序，把几何图追加在用户图后、其他派生细节图前。数量超过渠道预算时优先保留选中的原产品图；保留资源的相对顺序不变，用户列表本身不被删改。省略资源逐项写入报告并显示原因。Guide 被省略时会明确报告退化为 Prompt，不能称为已经使用结构引导。

尺寸图与已有派生图共用生成目录和素材索引，按物理数据缓存。预览不把系统图插入手动排序列表；生成时由后端重新准备并实际传入适配器。旧缓存不再引用后可通过现有未引用文件清理功能管理，避免删除仍被历史或任务引用的图片。

## 比例校验

`geometry_validator.py::GeometryValidator` 首期仅校验近正视矩形产品。自动定位复用本地产品蒙版、特征匹配和对应四角检测；缺少 OpenCV、原图、蒙版、特征覆盖或可靠四角时返回 `unknown`。

定位可靠后检查凸四边形、边长、角度和透视。宽高来自商品四角，经旋转与轻微透视的近似校正计算；独立校验函数也接受相机内参做标定单应性校正。不会使用整个输出画幅或像素包围盒代替商品测量，也不会把目标比例设为校正结果使所有图片通过。

自动流程没有相机标定。透视过大、指定斜视、产品无法区分或原图不能确定宽高轴向时返回 `unknown`。近正视图仍可能有单张图不可观测的缩短误差，因此 `pass` 仅表示本次相对比例检查通过。

相对误差为 `abs(测得比例 / 目标比例 - 1) × 100%`。默认提示阈值由尺寸配置定义，可修改：超过阈值提示 `warning`，超过两倍阈值为 `fail`，检测可靠且在阈值内为 `pass`。轻微透视存在时也提示 `warning`。厚度没有可信侧视几何依据时始终显示无法验证。任何状态都不构成真实厘米精度认证。

## 数据与开发入口

- `physical_dimensions.py` 与 `static/js/physical-dimensions.js`：独立换算、验证、比例和归一化函数；数据结构及版本以 `dimension_defaults`／`defaults` 为准。
- `width`、`height`、`depth` 保存毫米物理值，`unit` 只负责显示。派生比例和预览不能回写覆盖物理数据。
- `GeometryGuideGenerator`：相同几何图元产生 SVG／Canvas 预览和模型使用的 PNG；不调用生图模型。PNG 不含标注文字。
- `static/js/product-fidelity.js`：复用设置入口、原图身份、版本迁移、预览、校验展示与尺寸变更失效逻辑。
- `main.py::build_online_image_result`、`finish_product_fidelity`：已有任务、模型请求、结果处理和历史保存链路。

配置保存在原有 `fidelityConfig.dimensions` 或 AI 节点的 `runSettings.productFidelity.dimensions` 中，原图列表和用户提示词保留。节点复制、项目保存重开、撤销与重做均保留物理数据；尺寸或约束配置变化后，旧结构 ID、预览和校验报告失效。画布重做可使用 Ctrl+Shift+Z 或 Ctrl+Y，输入框保留其原有文本编辑快捷键。

旧尺寸格式按保存单位转换为毫米，把旧格式的 0 迁移为空值。旧项目不会自动开启新约束或改变其原有保真模式。

接口与浏览器测试使用独立临时目录和模拟模型响应，检查真实序列化代码和界面交互，不读取用户配置或调用付费模型。它们验证程序链路，不证明真实模型输出的尺寸精度。
