# 小美画布桌面版商品分析台

## 运行方式

- 小美画布桌面模式：首次在项目根目录执行 `npm install --prefix desktop`，然后双击根目录 `run.bat`。
- `run.bat` 始终以 Electron 桌面端为入口，不打开系统浏览器；缺少 Electron 时弹窗提示安装桌面依赖，不再回退到浏览器页面。
- Electron 壳会复用或启动 `http://127.0.0.1:3000` 的 FastAPI。

启动后直接进入商品分析台工作区。现有小美画布应用壳、左侧导航和其他功能页面保持原有行为。Electron 桌面版的淘宝、天猫、千牛、生意参谋、达摩盘、1688、小红书和抖音页面都在小美画布内部标签中打开，不创建外部浏览器标签。

桌面中间区域由 `WebContentsView` 显示淘宝/天猫/1688 商品页以及千牛、生意参谋页面。淘宝、天猫和 1688 请求会使用由当前 Electron Chromium 实际版本生成的 Chrome UA 与一致的 `Sec-CH-UA` Client Hints，不发送 Electron 产品标识；不伪造浏览器能力，也不自动处理登录、验证码或风控。登录、验证码和风控都在用户可见的官方页面中手动完成，应用不读取密码、Cookie 或 Authorization。

顶部浏览器工具栏按达比的标签页逻辑工作：新建/关闭/切换标签，地址栏回车导航，后退/前进使用当前 `WebContentsView.webContents.navigationHistory`，加载时刷新按钮变为停止，右上角菜单提供历史记录、书签和清单、JSON/HTML 书签导入、缩放、全屏和浏览数据清理入口。小美不保存密码；清理浏览数据会清除本地浏览历史，并在用户确认后清理淘宝/1688会话，不会清理千牛/生意参谋会话或用户书签。

## 商品分析工作区

右侧“问问小美”调用现有 `/api/chat`，通过 `link_job_ids` 绑定商品分析任务。商品详情标签加载完成后，右侧商品信息卡自动展开，显示商品缩略图、标题、商品 ID、类目、价格、销量、评价数、问大家数、SKU 数和核心/详细参数；下方资源卡与达笔顺序一致，已准备资源可下载、预览或勾选引用，评价/问大家只显示页面数量并在点击后采集正文。输入框手动输入 `@主图`、`@详情页长图` 等资源名也会绑定当前商品资源。点击淘宝商品卡片时，Electron 会拦截商品详情导航并创建新的内部商品详情标签；淘宝首页标签保持不变。快捷入口分别对应评价/问大家、详情页图、主图、主图视频和运营/人群数据。原始完整报告在“查看完整报告”抽屉中保留。

每个商品详情标签按商品 ID 记住自己的“问问小美”会话；切换到其他链接后，返回原标签会恢复原对话，新链接没有历史时显示新对话。切换期间旧链接的流式回答不会覆盖当前标签。

普通浏览器不再提供淘宝/天猫/1688 的备用 iframe。需要查看官方页面、内部多标签和手动登录时使用 Windows Electron 桌面版；普通浏览器仍可调用后端的商品分析专用 Edge 登录与采集链路，但不会在页面内嵌第三方站点。

桌面版商品采集先自动读取商品初始化状态、商品信息、主图、详情、SKU、视频和评价/问大家数量；详情图片只从已挂载详情 DOM、懒加载属性、初始化状态和商品标签打开期间的 `detail.getdesc` 网络响应读取，不滚动商品页，详情长图由图片 URL 直接下载拼接，完成后资源卡可纵向预览和下载。SKU 优先按达笔同样的 `res.skuBase.skus + res.skuCore.sku2info` 以 SKU ID 合并完整组合，首屏未返回矩阵时只检查当前可见规格入口，不为补采移动商品页，也不使用当前选中项生成伪行。主图视频合并商品状态中的 `item.videos`、嵌套视频地址、可见 `<video>` 和已加载媒体响应，没有真实地址就保留“暂无视频”；视频入口仅在已经可见时打开。评价/问大家正文不在基础采集阶段读取，用户点击对应资源卡后才启动达比式可见 Agent 链，截屏识别固定入口，用 CDP 鼠标点击/滚轮打开目标模块，并从当前动作触发的 `rateList`/`questionList` 响应解析真实样本。采集请求携带当前小美画布商品标签 ID，桌面端不会把另一个标签页的页面状态导入当前任务。操作中商品视图显示智能体图标、动画边框和停止按钮，成功快照通过 `/api/commerce-analysis/import` 进入同一套 FastAPI 合同；捕获失败不会再创建第二个后端采集任务，同一商品标签页短时间重复收到登录/验证快照时直接复用已有状态。浏览器版也使用 Edge + Playwright 执行自己的目标接口链。

## 运营数据

千牛或生意参谋页面必须由用户手动登录。桌面壳只提取白名单页面的可见文字和指标标签，发送到 `POST /api/commerce-analysis/operations/capture`。后端会在本地保存前清理 Cookie、Token、密码、Authorization 和手机号；记录可通过 `GET /api/commerce-analysis/operations/{id}` 或列表接口查询，并可绑定商品任务。

## 安全与故障排查

- 远程页面开启 `contextIsolation`、`sandbox`，关闭 Node 权限；非淘宝/天猫/千牛/生意参谋/达摩盘/1688/小红书/抖音域名禁止导航。
- Electron 未安装：执行 `npm install --prefix desktop`，安装完成后再次双击 `run.bat`。
- 商品页要求登录：点击“登录当前平台”（淘宝、天猫或 1688），在可见官方页面完成登录；商品详情标签从登录/验证页回到原商品并完成加载后会自动重试，若仍被拦截可点击对应资源卡右侧箭头重试。同一商品标签页的短时间重复登录/验证结果会复用，不会产生并发或重复失败任务。
- 页面没有返回真实视频时，报告会显示“当前页面未返回视频”，不会生成演示资源；SKU 页面未返回真实组合时显示未采集/缺失，不会用当前选中项或尺码表冒充 SKU 列表。
- 运营页面权限不足、风控或字段缺失会保留明确状态，不会伪造 GMV、ROI 或销量。
