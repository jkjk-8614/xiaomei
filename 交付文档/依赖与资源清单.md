# 依赖与资源清单

## 1. Python

| 依赖 | 用途 | 必需 |
|---|---|---|
| FastAPI | HTTP/WebSocket API | 是 |
| Uvicorn | ASGI 服务 | 是 |
| Requests | 同步 HTTP/下载 | 是 |
| HTTPX | 异步/流式 HTTP | 是 |
| mcp（>=1.12,<2） | MCP STDIO / Streamable HTTP 握手和工具列表测试 | MCP 连接测试需要 |
| Pydantic | 数据模型与校验 | 是 |
| python-multipart | 上传文件/表单 | 是 |
| Pillow | 图片格式、尺寸、裁切、预览 | 是 |
| NumPy | BiRefNet/BEN2 模型张量与透明遮罩处理 | 是 |
| ONNX Runtime GPU | BiRefNet 本地 CUDA 优先推理，失败时可回退 CPU | Windows/NVIDIA 推荐 |

精确安装版本可从交付包的便携 Python 环境执行：

```powershell
.\python\python.exe -m pip freeze
```

`requirements.txt` 保持宽松版本，以提高不同环境兼容性；生产部署可根据测试环境生成锁定版本。

Windows 本地抠图默认使用 `BRIA RMBG-2.0` ONNX 权重，模型首次使用时下载到 `data/models/background-removal/`。当前模型约 1.02 GB，输入为 1024×1024，模型元数据记录版本、文件大小和 SHA-256；当前电脑优先使用 `CUDAExecutionProvider`，实际设备以 `/api/background-removal/status` 返回为准。

`requirements.txt` 在 NVIDIA Windows 环境安装 `onnxruntime-gpu[cuda,cudnn]`；无 NVIDIA GPU 的环境可将其替换为 `onnxruntime`，代码会使用 CPU。RMBG-2.0 权重按 CC BY-NC 4.0 仅用于非商业场景，商业使用需另行取得 BRIA 授权；上游仓库和权重发布地址见模型状态中的 `source_url`。

保留的本地放大接口使用 Real-ESRGAN 官方 NCNN Vulkan 便携包，调用模型准备接口时下载约 43.4 MiB 到 `data/models/upscale/`，安装后约 51 MiB。它不新增 Python 依赖，也不要求 PyTorch；官方包、代码和模型来源为 `https://github.com/xinntao/Real-ESRGAN`，许可证为 BSD-3-Clause。SwinIR 与 SeedVR2 是可选 ComfyUI 引擎，不随交付包下载：SwinIR 需本地权重与标准模型放大节点，SeedVR2 需自定义节点、3B FP8 DiT（约 3.39 GB）和 FP16 VAE（约 501 MB）。模型文件属于运行数据，不进入源码发布包。

### 电商场景 ComfyUI 工作流的独立依赖

应用库的缺失节点安装来源与固定提交见 `ComfyUI/integration/comfy_node_registry.py` 的 `NODE_PACKAGES`；安装器把这些可选包及各自 `requirements.txt` 安装到 `ComfyUI/comfy_apps_runtime/` 的独立环境，重启后校验节点注册结果。主程序的 `requirements.txt` 不包含这些独立环境依赖。

这些依赖安装在 ComfyUI 自己的虚拟环境和 `custom_nodes` 中，不安装进小美画布的便携 Python：

- Qwen 图像理解：[1038lab/ComfyUI-QwenVL](https://github.com/1038lab/ComfyUI-QwenVL)，模型为 `Qwen/Qwen3-VL-4B-Instruct`，放在 ComfyUI 的 `models/LLM/Qwen/`。
- 抠图：[1038lab/ComfyUI-RMBG](https://github.com/1038lab/ComfyUI-RMBG)，节点使用的 RMBG 文件放在 `models/RMBG/RMBG-2.0/`，以节点源码 `AVAILABLE_MODELS` 为准。
- 图片去除 AI 感工作流的缺失节点：[ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack)（`ImpactInt`）、[ComfyUI_Qwen3-VL-Instruct](https://github.com/IuvenisSapiens/ComfyUI_Qwen3-VL-Instruct)（`Qwen3_VQA`）和 [comfyui-mixlab-nodes](https://github.com/shadowcz007/comfyui-mixlab-nodes)（`TextInput_`）。三者的固定提交与安装入口登记在 `ComfyUI/integration/comfy_node_registry.py`，由应用库按需安装到独立运行环境。
- 实验性 DLSS5 工作流：[HECer/ComfyUI-DLSS5](https://github.com/HECer/ComfyUI-DLSS5) 提供 `DLSS5EasyPipeline` 等节点，固定提交和节点清单登记在 `ComfyUI/integration/comfy_node_registry.py`。安装器拉取 Git LFS 文件并安装其 `requirements.txt`；插件仅支持 Windows/NVIDIA，首次运行前还需通过插件的 Runtime Setup 节点显式确认并安装其原生运行时。原生 DLL、VapourKit、可选模型及许可证以该插件的 `docs/RUNTIME_SOURCES.md` 为准，不进入小美画布源码包。
- Z-Image Turbo → Detail Daemon → SeedVR2 → 4K 工作流还可能使用 [cg-use-everywhere](https://github.com/chrisgoringe/cg-use-everywhere)、[ComfyUI-Image-Saver](https://github.com/alexopus/ComfyUI-Image-Saver)、[was-node-suite-comfyui](https://github.com/ltdrdata/was-node-suite-comfyui)、[ComfyUI-LG_SamplingUtils](https://github.com/LAOGOU-666/ComfyUI-LG_SamplingUtils) 和 [ComfyUI_essentials](https://github.com/cubiq/ComfyUI_essentials)；旁路分支启用时还需要 `ComfyUI-Detail-Daemon`、`ComfyUI-CacheDiT` 与 `ComfyUI-GGUF`。节点名、来源和固定提交以 `ComfyUI/integration/comfy_node_registry.py` 的 `NODE_PACKAGES` 为准。
- 工具节点：`yolain/ComfyUI-Easy-Use`、`kijai/ComfyUI-KJNodes`、`chflame163/ComfyUI_LayerStyle`、`Suzie1/ComfyUI_Comfyroll_CustomNodes`、`rgthree/rgthree-comfy`、`princepainter/Comfyui-PainterFluxImageEdit`（均为同名 GitHub 仓库）。Python 依赖以各仓库的 requirements 为准，并约束已验证的 PyTorch、Transformers 等基础库版本。
- LaMa：[shadowcz007/comfyui-mixlab-nodes](https://github.com/shadowcz007/comfyui-mixlab-nodes) 的原始 `nodes/Lama.py` 和 `simple-lama-inpainting`。本机通过 `custom_nodes/xiaomei_lama` 只加载此节点，原仓库保留为 `comfyui-mixlab-nodes.disabled`，避免整包替换 ComfyUI 的服务启动逻辑。权重放在 `models/lama/big-lama.pt`。Windows 中文目录下，`simple_lama_inpainting/models/model.py` 使用文件对象传给 `torch.jit.load`；重装该依赖后需检查此兼容修复。
- 基础生成模型：Black Forest Labs 官方的 `FLUX.2-klein-9b-fp8`；文本编码器来自 `Comfy-Org/flux2-klein-9B`；VAE 来自 `Comfy-Org/flux2-dev`。授权限制以模型发布页为准，无法匿名获取时需用户自行完成官方授权。
- 自定义 LoRA 必须由工作流作者提供匹配文件，不能仅改名替代。模型下载文件和第三方节点属于独立 ComfyUI 运行环境，不进入小美画布源码包。

## 2. 浏览器端资源

浏览器资源存放在 `static/vendor/` 及 `static/css/`、`static/js/`。主要包括图标、字体、Tailwind 浏览器版本或项目所需的本地第三方脚本。发布时整个 `static/vendor/` 必须原样保留，避免 CDN 不可用导致图标或样式缺失。

Fluent UI Web Components 与 Fluent 设计令牌由 `tools/fluent-ui/package.json` 声明，精确依赖树见同目录 `package-lock.json`。运行时加载 `static/vendor/fluent/` 中的本地产物；只有修改组件入口或升级依赖时需要 Node.js 与 npm：

```powershell
npm ci --prefix tools/fluent-ui
npm run build --prefix tools/fluent-ui
```

构建后同步更新引用这些资源的 HTML 缓存参数，并检查浅色、深色、自定义强调色及键盘操作。组件源码入口为 `tools/fluent-ui/entry.js`，公共样式规则见根目录 `DESIGN.md`。这些是浏览器依赖，不安装到便携 Python 环境。

商品分析台的浏览器采集器位于 `tools/commerce-analysis/`：

- 必须：新版 Edge/Chrome，采集只读取用户可见页面，不绕过验证码或风控。
- 推荐：Node.js 18+ 与 `tools/commerce-analysis/package.json` 中的 Playwright。进入该目录执行 `npm install` 后，系统优先使用 Playwright 采集器。
- 兼容：未安装 Playwright 时自动回退到内置 Node CDP 采集器；该回退不需要 npm 依赖，但仍需要 Node.js 和可启动的 Edge。
- 浏览器用户目录默认位于 `data/commerce_analysis_browser_profile/`，不要把其中的登录态和运行数据加入发布包。

手绘板节点使用本地镜像的 perfect-freehand 1.2.3（MIT），用于根据指针压力生成笔刷轮廓；源码入口与许可证见 static/vendor/MANIFEST.md 和根目录 NOTICE。

即梦 CLI 的 OAuth Device Flow 登录二维码使用本地镜像的 qrcode-generator 2.0.4（MIT）在浏览器端生成；登录地址和设备码不会发送到二维码第三方服务，源码入口与许可证见 static/vendor/MANIFEST.md 和根目录 NOTICE。

## 4. 操作系统资源

- Windows 10/11：推荐，支持原生文件夹选择和便携 Python。
- macOS/Linux：使用系统 Python/venv；文件夹选择行为可能不同。
- 浏览器：新版 Edge/Chrome，需支持 iframe、fetch、WebSocket、BroadcastChannel、File API 和 CSS backdrop-filter。
- 视频时间线成片导出需要本机 FFmpeg（建议 6+）。服务会优先查找系统 `ffmpeg`，也可在 `API/.env` 设置 `XIAOMEI_FFMPEG_PATH`；FFmpeg 不打包进 Python 依赖，导出文件写入运行时 `output/canvas-videos/`。

## 6. 本地 AI 应用库依赖

- `LatentNoised` 由 `RES4LYF` 提供，来源及固定版本登记在 `ComfyUI/integration/comfy_node_registry.py`；按需安装到独立 ComfyUI 环境，Python 依赖由节点包的 `requirements.txt` 管理。
- 固定清单之外的缺失节点可从 ComfyUI-Manager 公共节点映射精确发现。只有唯一的 GitHub HTTPS 仓库、同时登记在 Manager 节点清单并成功固定到提交时才自动安装；目录和提交缓存位于 `ComfyUI/comfy_apps_runtime/node-source-cache.json`。歧义、不安全 URL、未登记仓库或无法固定提交均保留为手动项。
- 主服务通过 `requirements.txt` 声明 `websockets`，接收本机 ComfyUI 的运行节点与进度事件。
- SeeThrough 及模型安装在独立运行目录，不加入主服务的 Python 依赖。安装器中的 `ManagedRuntime.prepare` 管理 diffusers、bitsandbytes、peft、accelerate，以及模型、调度器配置和 LaMa 补全权重；ComfyUI 自身依赖仍由其原环境提供。
- `ComfyUI/tools/comfy-app-bridge/` 是本地前端转换和任务输出桥接。PSD 浏览器资源及许可证登记在 `static/vendor/MANIFEST.md`。
- 安装、数据路径和故障排查见 [本地 AI 应用库](ComfyUI-AI应用库.md)。
