# 依赖与资源清单

## 1. Python

| 依赖 | 用途 | 必需 |
|---|---|---|
| FastAPI | HTTP/WebSocket API | 是 |
| Uvicorn | ASGI 服务 | 是 |
| Requests | 同步 HTTP/下载 | 是 |
| HTTPX | 异步/流式 HTTP | 是 |
| Pydantic | 数据模型与校验 | 是 |
| python-multipart | 上传文件/表单 | 是 |
| Pillow | 图片格式、尺寸、裁切、预览 | 是 |
| NumPy | BiRefNet/BEN2 模型张量与透明遮罩处理 | 是 |
| ONNX Runtime GPU | BiRefNet 本地 CUDA 优先推理，失败时可回退 CPU | Windows/NVIDIA 推荐 |

精确安装版本可从交付包的便携 Python 环境执行：

```powershell
.\python\python.exe -m pip freeze
```

`requirements.txt` 保持宽松版本，以提高不同环境兼容性；生产部署可根据测试环境生成锁定版本。

Windows 本地抠图默认使用 `BRIA RMBG-2.0` ONNX 权重，模型首次使用时下载到 `data/models/background-removal/`。当前模型约 1.02 GB，输入为 1024×1024，模型元数据记录版本、文件大小和 SHA-256；当前电脑优先使用 `CUDAExecutionProvider`，实际设备以 `/api/background-removal/status` 返回为准。

`requirements.txt` 在 NVIDIA Windows 环境安装 `onnxruntime-gpu[cuda,cudnn]`；无 NVIDIA GPU 的环境可将其替换为 `onnxruntime`，代码会使用 CPU。RMBG-2.0 权重按 CC BY-NC 4.0 仅用于非商业场景，商业使用需另行取得 BRIA 授权；上游仓库和权重发布地址见模型状态中的 `source_url`。

## 2. 浏览器端资源

浏览器资源存放在 `static/vendor/` 及 `static/css/`、`static/js/`。主要包括图标、字体、Tailwind 浏览器版本或项目所需的本地第三方脚本。发布时整个 `static/vendor/` 必须原样保留，避免 CDN 不可用导致图标或样式缺失。

商品分析台的浏览器采集器位于 `tools/commerce-analysis/`：

- 必须：新版 Edge/Chrome，采集只读取用户可见页面，不绕过验证码或风控。
- 推荐：Node.js 18+ 与 `tools/commerce-analysis/package.json` 中的 Playwright。进入该目录执行 `npm install` 后，系统优先使用 Playwright 采集器。
- 兼容：未安装 Playwright 时自动回退到内置 Node CDP 采集器；该回退不需要 npm 依赖，但仍需要 Node.js 和可启动的 Edge。
- 浏览器用户目录默认位于 `data/commerce_analysis_browser_profile/`，不要把其中的登录态和运行数据加入发布包。

## 6. 许可证

桌面版内置更新使用 Electron/Node.js 自带的文件下载、校验和进程能力，不新增 Python 或 npm 运行时依赖。发布更新由 GitHub Actions 构建 Windows/macOS 资产，并由 `scripts/create-release-manifest.mjs` 生成带大小和 SHA-256 的 `update.json`。两个平台的构建任务会在 CI 中安装 PyInstaller，把 FastAPI 后端分别封装成 `build/win-api/xiaomei-api.exe` 和 `build/mac-api/xiaomei-api`；这不是用户运行时需要单独安装的依赖。

项目自身许可证见根目录 `LICENSE`。第三方 Python 包、浏览器资源、CLI 和外部平台遵循各自许可证与服务条款；再分发前应逐项确认。
