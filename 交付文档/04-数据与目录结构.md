# 数据与目录结构

## 1. 根目录

```text
小美画布/
├─ main.py                    FastAPI 后端
├─ requirements.txt           Python 依赖
├─ run.bat                    Windows 启动
├─ static/                    前端页面、脚本、样式、浏览器依赖
├─ workflows/                 内置与自定义 ComfyUI 工作流
├─ CLI/                       Codex/Gemini/即梦 CLI 安装脚本
├─ tools/                     浏览器/Photoshop/CLI 辅助工具
├─ packages/                  离线或便携依赖资源
├─ python/                    Windows 便携 Python 运行环境
├─ API/                       .env 配置目录
├─ assets/                    上传、素材库、生成素材
├─ output/                    输出目录
├─ data/                      JSON 数据与画布/会话
├─ logs/                      运行日志
├─ 交付文档/                  本交付说明
└─ AGENTS.md                  Codex 接手入口
```

商品分析台的代码入口和运行数据：

```text
tools/commerce-analysis/
├─ collector-playwright.mjs   Playwright 可见浏览器采集器
├─ dabi-taobao.cjs            达笔淘系 rateList/questionList 协议解析
├─ collector.mjs              CDP 兼容采集器
└─ package.json               Node/Playwright 可选依赖

desktop/
└─ dabi-agent.cjs             Electron CDP 截图、鼠标/滚轮/键盘与网络响应 Agent

data/commerce_analysis/
├─ analysis.sqlite3            商品任务、运营报表、Agent 会话和 Merchant 变更账本
└─ snapshots/<job_id>/         snapshot.json、collection.json、原始页面文件

data/commerce_analysis_browser_profile/
└─ Edge 本地用户目录            用户在可见 Edge 中自行登录淘宝后的本地会话；不上传、不进入发布包
```

桌面版 Electron 内嵌页面不使用上述 Edge 用户目录，而是按站点使用独立的 Chromium 持久会话：淘宝/天猫为 `persist:xiaomei-commerce`，1688 为 `persist:xiaomei-1688`，千牛/生意参谋为 `persist:xiaomei-qianniu`。三者的 Cookie、LocalStorage 和登录状态互不共享。

`analysis.sqlite3` 中的 `merchant_changes` 是经营助手专用账本：保存 `conversation_id`、关联商品任务/商品 ID、变更类型与状态、变更前后 JSON、真实证据 ID、护栏、来源摘要和审批/应用时间。它不写入商品快照表，也不保存店铺账号、Cookie、API Key 或平台写入凭据。

`packages/photoshop-bridge/` 是可选 Photoshop UXP 插件源码。项目不会自动写入 Photoshop 安装目录，需由用户通过 UXP Developer Tool 加载其 `manifest.json`。

## 3. 运行数据

| 路径 | 内容 | 发布包策略 |
|---|---|---|
| `API/.env` | API Key 和环境变量 | 排除，提供 `.env.example` |
| `data/api_providers.json` | 平台设置，可能关联密钥变量 | 发布包使用空数据 |
| `data/canvases/` | 用户画布 JSON | 排除 |
| `data/projects.json` | 画布项目分组 | 空数据 |
| `data/canvas_shares.json` | 画布分享 token 摘要、权限、有效期和撤销状态；不保存原始邀请 token | 排除 |
| `data/asset_library.json` | 素材库元数据 | 空数据 |
| `data/asset_registry.json` | 统一素材索引：稳定素材 ID、当前/旧 URL 别名、来源、派生关系和回收状态 | 排除，运行时产生 |
| `data/asset_trash/` | 已移入回收站的本地素材正文及其随附文件 | 排除，运行时产生 |
| `data/prompt_libraries.json` | 提示词库 | 可由程序初始化 |
| `data/storage_settings.json` | 图片空间根目录、三个子目录和旧目录兼容映射 | 排除/重置 |
| `data/canvas_tasks.json` | 画布后台任务状态，服务重启后保留已完成/失败记录并标记中断任务 | 运行时产生，不含 API Key |
| `data/scheduled_tasks.json` | 定时任务计划、启停状态和最近一次运行结果 | 运行时产生，不含 API Key |
| `data/commerce_analysis/` | 商品分析任务 SQLite、商品快照、原始 HTML/JSON、`operations/` 运营数据记录及 `merchant_changes` 变更账本 | 排除，运行时产生 |
| `data/conversations/` | 按用户标识保存的 GPT/商品分析台共享对话历史 | 排除 |
| `data/agent_skills/` | Agent Markdown Skill、导入索引与临时目录 | 内置示例可保留，用户新增内容迁移时备份；`.imports/` 仅用于浏览器选择文件夹时的短暂临时文件 |
| `data/media_previews/` | 预览缓存 | 排除 |
| `data/models/background-removal/` | BRIA RMBG-2.0、BiRefNet General Lite、旧版 BEN2 模型及版本/校验元数据 | 首次使用时下载，运行数据，不进入源码包 |
| `tmp/updates/` | 桌面版下载中的安装包临时文件 | 运行时产生，不进入发布包；校验失败或取消后清理 |
| `assets/` | 用户上传和生成图片 | 保留目录，不保留个人文件 |
| `history.json` | 历史生成记录 | 发布包初始化为 `[]` |
| `logs/` | 日志 | 排除 |
| `__pycache__/`、`*.pyc` | Python 缓存 | 排除 |

### 提示词案例库

`data/prompt_cases.json` 保存独立的生成案例索引，`assets/prompt_cases/<case_id>/` 保存案例专属媒体副本。两者都属于运行数据；迁移小美画布时应与 `data/`、`assets/` 一起备份。它们与文字模板库 `data/prompt_libraries.json` 相互独立。

默认抠图模型为 `bria-rmbg-2.0`，模型文件和同名 `.json` 校验元数据位于 `data/models/background-removal/`。模型只在本机推理；迁移电脑时可以一起备份该目录，也可以删除后在下一次使用时重新下载。

## 4. 备份与迁移

迁移个人工作环境时，可以额外复制以下数据，但不要公开分享：

```text
API/.env
data/
assets/
history.json
workflows/custom/
```

如果只迁移源码，不要复制上述个人数据。

## 5. 文件夹选择

素材管理支持 Windows 原生文件夹选择。现在统一使用“图片空间”根目录，并自动包含三个子目录：`上传素材`、`生成素材`、`本地素材`。保存目录记录在 `data/storage_settings.json`；升级时旧的三个绝对路径会作为兼容来源保留，点击保存图片空间后可合并到新目录，同名文件不会被覆盖。换电脑后旧绝对路径通常失效，应重新选择图片空间根目录。

`生成素材`同时保存生成图片和视频；图片空间页面会按媒体类型展示，并支持视频预览、下载和删除。

## 6. 统一资产索引（P0）

统一索引不替换现有物理目录：上传、素材库导入和新生成媒体会立即登记稳定的 `asset_…` ID，原有路径或 URL 仍作为兼容地址保留。画布节点会同时保存 `asset_ref_id` 和原 URL；旧画布、旧历史记录、图片空间文件与素材库条目按需补入索引，也可调用 `POST /api/assets/index` 做只索引、不移动文件的扫描。读取素材库、打开和保存旧画布不会自动全量扫描其中的媒体，避免大画布或大素材库阻塞本地服务。

删除前后端会实时扫描画布和历史引用。仍被引用的素材不能移入回收站；未被引用的本地素材会先移动到 `data/asset_trash/`，可通过统一素材接口恢复，确认后才允许彻底清除。若删除的是整个素材库分类，恢复其中素材时会按保留的分类信息重建原分类。迁移旧素材不复制、不改写旧路径，因此换目录或升级时仍须保留原有目录兼容配置。

## 7. 编码

- 源码与 JSON 应使用 UTF-8。
- Windows PowerShell 读取中文时出现乱码不一定代表文件损坏；应明确指定 UTF-8。
- 禁止用系统默认编码批量重写 HTML/JSON。
